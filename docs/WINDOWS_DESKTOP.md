# Windows 桌面使用

下载 Windows 安装包后，双击 Setup.exe 等待安装完成，再用桌面 RootSound 图标启动。
默认安装目录为 D:\Apps\RootSound，工程保存在安装根目录下的 project。

源码工作树使用项目根目录的 RootSound.exe，依赖同目录 .cache 中的完整构建。
源码工作树首次运行需构建，见 DEVELOPMENT.md。

## 打开与编辑

欢迎页点击“开始”进入实际 project 文件夹的乐曲库。文件夹逐层进入，顶部路径返回上层。
图标／名称按页显示；左右方向键和按钮首尾循环，文字输入时保留光标移动。
点原生工程、MIDI 或受支持 MusicXML 直接编辑原文件；打开不会自动生成 .rootsound 副本。

当前是一张纵向音乐卷帘，横向为音高、纵向为时间。左侧音符组分别选择、试听和编辑；
同音色组可拖拽合并，一次撤销恢复。选中左栏音符组时，其他组变暗，
在空白处点击或拖动会写入当前组。未选中音符组时，拖空白移动卷帘。
明亮的音符可直接拖动或拉伸底边，悬停时按 Alt 并滚动可微调时长。右键点空白处清除组选，右键点音符删除它。按住右键拖动可擦除扫过的所有音符，包括变暗的音符。整次拖动可一次撤销。选中音符组后按 Shift+Delete 可以移除整组，有音符时会先确认。
新建或拖动音符时，音符头靠近可见的拍线或细分线会轻微吸附，离线较远时仍可自由放置。调整速度、持续秒长与拍长是不同操作。
播放线右端的红字显示当前位置，精确到毫秒。
速度段的细标签打开 BPM／敲击定速／每拍细分面板，多速度段是可选高级工具。
拖动相邻速度段的分界时，分界沿上方拍线移动，下段可以从拍中开始，已有音符的播放时刻保持不变。

键盘演奏可以启用，旧 QWEASD 编辑微调已取消。设置还提供练习重学与高级工具开关。
首次启动可以观看或跳过引导。引导在独立内存乐谱上自动播放。

## 保存与退出

主页的“开始”打开乐曲库以选择乐曲。编辑时点击“保存”或按 Ctrl+S，底部显示“另存为”和“保存”，完成后留在编辑界面。保存格式为 .rootsound。
没有未保存修改时，退出乐曲会回到主页，关闭 RootSound 会结束程序。有未保存修改时，两个入口都会打开乐曲库，底部依次显示“直接退出”“另存为”“保存”。保存成功或点击“直接退出”后继续退出，关闭乐曲库则回到编辑。
标题旁的星号表示有未保存改动。格式和文件操作见 MUSIC_FILES.md。

## 常见问题

- 提示缺少 .cache：运行文件不全，需在该工作目录完成 desktop:build 或使用完整发布包。
- 提示另一个窗口使用本机资料：副本共用默认数据目录，开发测试用独立 --data-dir。
- 修改源码后界面没有变化：根 exe 不自动重建，检查该目录构建是否成功及当前指针。
- 原 MIDI 与作者声音不同：MIDI 没有原录音，GM／SysEx／自定义音源存在边界，见 GM_INSTRUMENTS.md。
