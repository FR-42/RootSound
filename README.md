## 一键打开

**日常双击根目录的 `RootSound.exe` 打开桌面窗口。** 这是固定的无控制台入口，直接打开最近一次完整构建的版本，不在启动时下载依赖或编译源码。关闭 RootSound 窗口即可退出，不需要网页服务或外部浏览器。

**`RootSound.bat` 仍然保留，可以一键构建并打开。** 第一次取得源码、修改源码后希望自行构建，或根 EXE 缺失时使用它；首次会获取开发依赖并构建，以后源码没有变化时直接启动。构建同时生成根 `RootSound.exe`，后续日常使用可直接点 EXE。

首次构建需要已安装 Node.js 24、.NET 9 SDK 和 WebView2 Runtime（微软提供的桌面内嵌网页运行组件），本机已具备。构建后的日常使用不需要 Node.js 或 SDK，仍需要 .NET 9 桌面运行环境和 WebView2；根启动器使用本机 Windows .NET Framework。首次获取开发依赖可能需要联网，当前创作、试听、导出与本地保存可离线使用。启动器不会自动安装系统运行环境。

新版本在独立构建目录准备完成后才切换启动目标，不会覆盖正在使用的旧程序。**更新后先关闭使用同一资料库的旧 RootSound 窗口，再双击根 EXE 打开新版。** 同一个资料库只允许一个实例使用。根 EXE 需要配套构建目录和文件，不能只复制这一枚 EXE 到另一台电脑；当前尚非安装包或自包含便携发行版。具体目录与恢复方法见 [Windows 桌面使用说明](docs/WINDOWS_DESKTOP.md)。

手动启动：

```powershell
npm run desktop
```

共创入口已从欢迎页、导航、素材分类和启动设置中隐藏；旧共创启动位置回到音色制作。当前优先完善手动创作。素材栏跟随正在编辑的作品归属，避免显示其他歌曲里不能直接使用的素材；独立音色或乐句显示公共素材。已有歌曲时，顶部进入乐句会优先接回本曲已有内容，未完成的公共稿仍保留。

顶部“采样获取”提供“导入音频…”和“录一段”。导入保留原文件字节，能否解码取决于格式和运行环境；麦克风录音需要正常授权，当前保存为单声道浮点 WAV。暂定单文件 16 MiB、解码后 120 秒和 64 MiB，系统播放声音的直接录制仍未实现。

完成获取后可点 **“用这段声音制作音色”**，保存原采样并进入独立工作区。选择播放范围、原音高并试听；“延长声音”里可启用循环，保留声音开头并重复指定片段直到音符收音。参数单独保存，原文件保留。当前移调仍同时变速，尚无保持时长移调、多采样键位/力度映射或自动寻找平滑循环点。

采样点“保存采样”后才进入资料库。未保存内容只在内存中，切换工作区会保留本次已完成的采样，但完全退出软件会丢失。导入、录音或打开另一采样前，如有未保存修改，会提供“保存后继续 / 放弃并继续 / 返回”；取消、获取失败或保存失败保留原采样，可继续重试。离开工作区会停止并取消未完成录音。

单人清唱或哼唱可点 **“把哼唱变成旋律”**，再点“听听识别结果”。喜欢后选“去细调”才保存乐句，不必先保存原采样；想保留原录音，仍需另点“保存采样”。它按演唱时间整理音符与休止，不猜歌曲速度或调性，也不自动纠音。超过 30 秒会拒绝，不自动截断；带伴奏、多人演唱和滑音等内容可能不准确，需试听核对。当前不是 AI 或人声分离，尚未经过真实人声和界面体验验收。

旧“未定义”族仍可保留，通过更换音色重新发声。选总音符时也保留双击清空的“删除”；选具体音符后调整它的独立参数。
Q/E 调声像，W/S 调音量，A/D 每次移一格；150毫秒内连续两次同方向 A/D 合计移一拍。

先在“设置”开启“键盘演奏”，旋律部选中总音符后可用 `c f v g b n j m k , l .` 逐格输入 C4–B4，
Z 降一个音区、X 升一个音区，并将高亮音区中心移入可见区域。音符写到播放头右侧紧邻的小格线，长度先取一格对应的秒数，
播放头移动到这条线；下次按键再前进一格。空格只前进一格、不创建音符或启动播放。
新生成的音符自动选中，控制台随即显示其参数，同时保留连续输入的音色上下文；撤销、重做时音色仍存在即可继续输入。
手动选择已有音符或右键空白会退出这次连续输入。Backspace撤销演奏生成的音符时回到该次录入前位置，重做恢复录入后位置；普通编辑不移动播放头，Delete才删除选中音符。
旋律、节奏的控制台都只在右侧编辑区下方显示，左侧总音符栏或音色栏保持全高；短音符按真实时长显示宽度，不用额外留白撑大，长音符仍横跨其实际占用的格子。
右键编辑区空白只清除选择并关闭控制台，右键音符或沿路径划过音符仍执行取消。
映射、音区边界与使用条件见 [Windows 使用说明](docs/WINDOWS_DESKTOP.md)。

节奏部右端的“创作”进入步进编辑。每个音色对应一条宽行，左侧音色框与右侧同行保持对齐，
上下滚动或调整行高时一起移动。操作沿用旋律编辑：选音色、放音符、拖动、右键取消、调节控制台。
节奏控制台显示音色、音量、开始位置、声像、秒时长和力度，不显示音高。跨行拖动把音符交给目标行的音色，
保留音符身份与实际音高；新节奏音符暂以 C4 触发，这是当前起点选择，尚未提供每音色根音设置。
两部各自编辑和显示，详细编辑只播放本部，总览、保存和歌曲输出包含同一乐句的两部内容。旧未标记部门的音符按旋律部读取。

**乐句顶栏改变 BPM 时，只改变音符开始时间的间距，单个音符保留原来的秒数。**
音符开始位置按拍/格记录，BPM 提高时更早触发，持续0.5秒的音符仍持续0.5秒，音高与音色也不改变。
每拍四格同时用于钢琴卷帘和步进音序器。

歌曲编排**各乐句保留原速**，这是用户已确认的规则。例如原速 90 拍/分钟的乐句放入背景为 120 拍/分钟的歌曲，仍以 90 演奏；编排 BPM 只调整背景网格，不改写源乐句的音符时序。

旧详细编辑器的多声音、钢琴卷帘及成组操作仍保留在源码和数据模型中，不作为新谱写入口；本轮使用新的旋律编辑器。
已有乐句按实际完整长度展示和试听，超过16拍也不裁切；歌曲中的完整使用和导出保留全部内容。
RB58 仅完成空白工作台结构的记录已由旋律和节奏工具扩充；更多创作工具仍可继续发展。

播放时调整声音、乐句或歌曲会沿当前进度实时反馈，拖动途中即可试听变化；松手才保存一次修改，取消或保存失败会恢复临时试听。更换作品或切换工作区仍结束当前试听。乐句和歌曲的撤销重做随各编辑稿保存，关闭重开后可继续使用，每稿当前最多 64 步；升级前没有记录的操作不能追溯恢复。普通撤销只改编辑稿，联合应用可整体撤回当次选中的位置；之后另行保存的作品不随编辑稿撤销回退。

## 保存、引用与文件

**每个新建桌面歌曲项目默认保存为安装根目录的 `project/歌曲名.rootsound`。** 本机即 `D:\RootSound\project\歌曲名.rootsound`，不再为歌曲创建子目录。一个文件包含歌曲、音色、乐句、原始采样、编辑稿和撤销资料；复制到另一台能运行兼容 RootSound 的设备即可继续编辑。`.bak` 是上一次写入前的恢复副本，不列入乐曲库。各项目独立存储，不读入旧全局资料库；`%LOCALAPPDATA%\RootSound` 继续保留宿主缓存及应用锁。详细设置只修改本次新建的保存目录；默认目录外的工程可用乐曲库底部文件夹按钮选择。旧版 `project.json` / `materials.json` 目录项目仍能识别与保存，不自动删除；可用“另存为”生成新格式文件。

原始采样当前没有持久编辑稿，未保存的采样不在资料文件中。写入失败明确报错，原数据保留，不伪报保存成功；损坏项目不会被当作空库清除。`.rootsound` 是完整工作项目；下方 `.rsproject` 保留为旧版内容交换协议。

本机编辑稿随完整 `.rootsound` 项目持续保留，用于关闭后恢复；旧版 `.rsproject` 内容交换范围另见下文。**素材管理只显示当前歌曲工程**：同一实体的已保存状态与有效编辑稿只列一次，优先展示当前编辑状态；只为旧保存或撤销恢复保管的内容不列为当前素材。公共起点只在实体栏的“素材库”另列。没有当前歌曲时，素材管理为空，不混入独立音色和乐句。

乐句引用音色，歌曲引用乐句。**一个使用位置引用时，普通保存覆盖原实体；多个位置引用时，为当前这一处新建实体。** 双击歌曲片段进入乐句，再调整音色，沿途必要的乐句也按同一规则判断。同一位置的已保存状态和编辑稿合算一次，临时细调稿不增加引用；普通稿新添的引用仍受保护。库内直接打开实体，零或单引用可覆盖，多引用另存副本；明确“另存”始终创建新身份。

**不同歌曲的素材彼此隔离。** 从公共起点为歌曲选用素材时，会带入本曲独立的乐句、音色及原采样；同一首歌重复采用未变的同一来源，会复用本曲已有素材。另存新歌曲、从共创建立歌曲或打开工程，也会保留独立身份。公共素材仍统一保管，但修改一首歌的素材不会改到另一首。

**同一首歌、同一种类的不同素材不能重名。** 音色“雨”和乐句“雨”可以并存；同一音色被多个乐句引用也没有问题。另一首歌可以使用同样名称。手工改成重名会提示并保留修改，自动生成副本时会补充数字；从排列移除但仍保留在本曲的素材也保留其名称。旧库不会在打开时批量改写，编辑相关歌曲时才逐步隔离；旧历史撤销仍可能恢复当时的共享状态，再次编辑会重新隔离。

尚未交给歌曲的公共素材也按种类避免重名；这补上了先前只约束歌曲内部的遗漏。手工重名会要求换名，新建、派生或导入默认补数字，不同歌曲可以同名的规则不变。工作稿与它对应的已保存实体是同一份内容的两个状态，不当作两个重名音色。

音色制作的 **“新建音色”** 在细调状态下也可使用。可从纯净声音、琴键、拨弦、铃声、主音、低音、铺底、鼓和风声等 12 个电子起点开始，也可走采样路线。每个电子起点都可编辑声源、音高、音量的起音/回落/保持/收音、明暗和音高回落；音高微调及额外变化按需展开。旧三套配方保持原声，只在实际编辑时转换。当前没有逼真的钢琴、吉他等真实乐器素材库，电子起点不等于真实乐器仿真。

音色制作只突出一个“保存”；“另存副本”和“应用到其他位置…”收在旁边的“⋯”中，有相应操作时才显示。从当前使用位置进入编辑时不提供绕过该位置的另存。旧详细编辑器支持“应用到其他位置…”和“联合修改…”，从乐句内调整声音时，选中的其他位置等到保存这段乐句才一起生效，取消不提前改动它们。新谱写工作台暂不显示这些旧编辑控件；既有引用与一次联合应用的撤销保护保留。

同一首歌内复制片段仍只复制引用，不展开整套依赖；素材管理中的声音或乐句“另存副本”也保留本曲下层引用。跨歌曲采用和另存新歌曲则建立独立依赖。嵌套细调先暂存，外层保存才覆盖或分离，取消不提前影响原实体。覆盖之后若又保存或修改了上游歌曲，旧事务撤销会拒绝影响这个后来保存的版本；普通未冲突的撤销重做仍支持跨重启恢复。

| 文件 | 用途与范围 |
| --- | --- |
| `.rootsound` | 完整本机歌曲项目，包括当前声音、采样、乐句、歌曲、编辑稿及历史；新建、打开、保存和另存为使用此格式 |
| `.rssound` | 单个无外部依赖的电子音色，含当前名称和全部参数；旧配方使用 v1，新合成结构使用 v2，当前均可读取；采样原件仍随 `.rsproject` 携带 |
| `.wav` | 可在其他播放器直接播放的无损音频；当前界面输出 48 kHz、24 位、双声道，不含可编辑音符和引用 |
| `.rsproject` | 当前歌曲稿、显式工程成员及其依赖，含乐句、音色全部参数与原始采样；可继续编辑，不是可播放音频或整库备份 |

在歌曲编排点 **“保存”** 或按 **Ctrl+S**，直接保存当前项目文件，不弹位置选择。
**“另存为”** 只填新名称，默认“原名称 1”；确认后直接在安装根 `project/` 的乐曲库生成独立副本
并进入该副本，原项目保持原样。欢迎页“开始”打开乐曲库，点击歌曲即可继续；底部文件夹选择 `.rootsound` 文件。
下方 `.rsproject` 是保留的旧版文件交换协议，新歌曲界面以 `.rootsound` 为保存入口。

打开工程会一次导入独立的新歌曲、乐句、音色和采样身份，保留包内共享关系，不覆盖同名作品；原先的编辑稿仍保留。在素材管理中明确另存的副本属于本曲成员，即使尚未放进编排也随文件保存。没有附加成员时继续使用 v1；有显式成员时使用 v2，当前可读取两版。文件严格收齐歌曲与成员的依赖，拒绝缺失、循环或无关孤立内容；不携带其他歌曲、旧保存、撤销记录、编辑上下文或本机偏好。原始采样只携带一份，不依赖原电脑路径；压缩格式仍需要目标环境能解码。暂定上限为 32 MiB、8192 份内容。

Windows 原生对话框成功写入后才提示文件已保存；取消或写入失败不报成功，并保留当前创作。浏览器验证版只能报告“已发起下载”，文件是否完成需在浏览器中确认。

此前浏览器作品不会自动搬到桌面。可在原地址与端口打开浏览器验证版，通过工程文件搬运整首歌曲及所用素材，或逐个导出、打开声音文件。当前没有独立乐句交换文件或整库迁移功能。
