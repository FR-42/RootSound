# 桌面操作引导

桌面版首次打开会询问「是否观看引导」。选择观看会从第一幕开始，结束后回到待打开的工程或开始页。选择跳过会直接进入该页面。也可以从桌面开始页左下角点击「操作引导」。引导从白屏开始，在画面中央印出每一幕的标题和简短说明。右边缘显示渐隐的蓝光和「下一幕」时，点击右侧区域或按 Enter 可以继续。在引导画面中连按两次 Enter，间隔不超过 175 毫秒，可以提前跳过当前幕。卷帘幕可直接按回车跳过。卷帘、音符、琴键与列线三幕在出现 0.5 秒后显示「下一幕」。BPM 一幕在首次点击左下角数字 0.5 秒后显示「下一幕」。敲击定速窗口内，Enter 用来应用有效的敲击结果。从播放头一幕起，空格可以开始、暂停和继续播放，播放头可以拖动定位。第三幕的播放头首次开始移动 0.5 秒后会显示「下一幕」。顶栏是最后一幕，按 Enter 结束引导并返回欢迎页。

播放和编辑沿用正式卷帘。展示音符时只开放平移。从第四幕起，可拖动卷帘的下边界来调整长度。音色一幕先让三张音色卡移到左上角，再依次练习选中音色、添加音符和右键取消选中。练习添加音符后，右键取消选中，0.5 秒后出现「下一幕」。等待操作的提示以 1.6 秒为一轮，从白底黑字过渡到蓝底白字，再变回白底黑字，底色向四周渐隐。第七幕开放缩放，第八幕加入细分线和每拍细分设置。第九幕依次提示移动、删除、改时长和撤销。完成一条后显示下一条，完成撤销后等待 0.5 秒出现「下一幕」。练习项目在内存中保存，关闭引导时随会话清除。再次进入会从白屏开始。

构建桌面渲染器后，可用 Electron 在隔离的隐藏窗口中运行 `scripts/test-music-guide-ui.cjs`。检查包括分步显示、按键时机和实际播放时钟、输入权限、练习保存和退出，以及返回欢迎页。测试会检查练习未调用本机文件接口。此检查不经过物理扬声器。
