# 歌曲编排

独立的个人音乐流程实验。把“乐句谱写”导出的 `.rsphrase` 摆到多轨时间线上，组合成歌曲。

双击上一级目录的 **歌曲编排.exe**。日常启动不编译、不联网。修改源码后用旁边的
**构建并打开歌曲编排.bat**；入口需要 `song-studio/.builds/` 配套文件。

## 开始编排

1. 点击左侧 **导入乐句**，可一次选择多个 `.rsphrase` 文件。列表显示名称、小节数和原速度。
2. 把列表中的乐句拖到右侧任意轨道、任意小节。一个乐句可反复拖入；不同轨道和同轨乐句都可重叠。
   点击时间线空白处设置红色播放位置，再双击列表乐句，也能把它放到当前轨道和位置。
3. 拖动乐句块改变位置或轨道。默认吸附到四分之一拍，可选择整拍、整小节或自由；按住 Shift 暂时自由微调。
   底部可准确设置起始小节、拍、轨道、音量，或复制、删除选中乐句块。复制放在该块末尾，方便接成长段。
4. 点击 **播放** / **暂停**，或按空格。点击或拖动顶部小节尺可以定位；停止回到开头。
   缩放滑块或 Ctrl＋滚轮改变时间线比例。滚轮上下滚动轨道，Shift＋滚轮横向滚动，也可用滚动条。
5. 点击轨道名选中轨道，在下面改名、音量和静音。双击轨道名切换静音。可以增加轨道、删除空轨道。
   Ctrl＋D 复制乐句块，Delete 删除；Ctrl＋Z / Ctrl＋Y 撤销、重做，最多保留 50 步。

乐句默认保留原速度：例如 60 BPM 的一小节乐句放到 120 BPM 的歌曲中，实际占两小节。
选中乐句块后勾选 **跟随歌曲速度**，才会按歌曲速度演奏；改变速度不会转调或修改源乐句文件。
播放中的已提交编辑会经短缓冲反映；拖动松手提交一次修改。

## 保存与导出

- **保存歌曲项目**（Ctrl＋S）：选择位置保存 `.rssong`。它包含所有导入的乐句、准确采样音频、音色设置、
  轨道、摆放位置和音量。用 **打开歌曲** 继续编辑，不依赖原来的乐句或音色路径。
- **另存为**：保留原项目，另存一个版本。打开/新建/退出前会提醒保存未保存修改；文件变更后覆盖会转为另存。
- **导出 WAV**：通过系统文件保存窗口导出 48 kHz、24 位、立体声整曲，包含中间空白、重叠混音和自然尾音。
  使用与试听相同的发声、增益和峰值保护。导出有进度、可取消；完成后才替换目标文件。
- 私有自动恢复副本位于 `%LOCALAPPDATA%\RootSoundExperiments\SongStudio\`，启动时询问是否恢复。
  编辑只改小型说明，未变音色复用缓存。明确保存或放弃后清除恢复入口，不扫描清理用户文件。

`.rssong` 是本实验的歌曲格式，尚不能交给 FL Studio 或主工作站打开。本模块借鉴 Playlist 的摆放工作方式；
不包含 FL Studio 的完整混音台、插件、自动化或 `.flp` 兼容。导入只支持现有 `.rsphrase`，音符细调仍在乐句谱写中进行。
导入是快照；之后修改原乐句文件不会自动改变已导入歌曲的声音。

首版固定 4/4，20～300 BPM；最多 64 个导入乐句、32 条轨道、512 个乐句块、十万个编排音符，
音色总量 512 MiB、128 个同时发声音符，最长两小时且不超过 2048 小节。这些是可调整的实验容量。
超过同时发声容量会明确报告；不会静默丢音。试听只在点击播放后打开声音设备。

## 构建与检查

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File experiments/music-workflow/Build-SongStudio.ps1 -Test
```

隔离检查使用生成的乐句、模拟播放设备和离屏绘图，不打开实际应用窗口、不读屏或控制桌面，不播放真实声音。
覆盖导入→摆放→存档重开→WAV、文件损坏/取消保护、原速/跟随速度、重叠/静音、尾音、设备时钟、定位、拖动和布局。
真实听感、系统文件窗口和拖动手感仍需实际使用确认。主工作站、真实资料库和前面工具的源文件不会被本模块改写。
