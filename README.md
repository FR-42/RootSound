RootSound (已经趋势)



这个项目起源于我的胡乱愿望，经历了两次根本目的的变化，现告此终结



死亡原因：

20+天没有达到最小化验证成果（做出来cosmica、melodiniq、vulcanus等音游曲音乐的其中一段），继续进行学习成本极高



目的的变化：

给自己做一个最趁手的音乐编辑器 -> 

做一个大众化、零基础、易上手的音乐编辑器 -> 

做一个能让新手快速上手做出来喜爱音游曲的音乐编辑器



为什么失败：

1. 首次上手重型ai项目开发（一周20亿token是重型吗？）

2. 出发点是失败的（一开始不是项目，而是为了个人学习、爱好）

3. 目的极其困难



我的收获：

1. 即使是gpt旗舰ai，也不聪于艺术领域

2. gpt有繁重冗杂的验证习惯

3. 音频文件非常消耗token和额度，搭配上一条尤其恐怖

"\RootSound.bat" 项目本体，打开即玩
