## 亲手操作引导（RB142，2026-11-05）

网页与桌面共享基础练习和分段速度练习。首次进入自动开始，双击“跳过”退出，
以后可在“设置”里重新学习。真实工作台旁只显示一个短提示，实际完成对应动作才推进；
播放时音符轻微点亮。练习另用独立内存工程，浏览器下载练习工程或音频不会改动公共
40音符示例及访客原来的草稿；刷新仍按原规则载入公共示例，只有练习状态单独保留。

“分段调整速度”默认关闭，基础编辑器不显示新增卷帘的＋；拖动末段底边仍可扩展。
打开包含多卷帘的文件会先提示“启用并打开”，取消则保留当前草稿。首次开启会进入
专属练习；正在使用此能力的工程内不能关闭它，需先退出工程。原工程音符和速度不变。
本轮本地网站构建与隔离验证不等于 GitHub Pages 已部署。

## 播放结束

本地和网页共用播放规则：按最后一个可播放音符的实际持续时间，找到它结束时所在
小节的末端，归零并暂停，不等待之后的空小节。跨BPM卷帘／长音／弱起也按原时钟
计算，隐藏音符不延长试听。手动定位到最后音符之后的空白区时，临时允许播放到
完整编辑长度；停止或定位回音乐区域后恢复自动结束。编辑中重新计算结束点，
播放头逐帧移动只读取缓存，不反复扫描全部音符。只影响试听，不改工程或导出长度。

## 默认示例

用户提供当前Chrome页面下载的工程，含40个钢琴音符、148BPM。原文件只读保留；
`website/examples/starter.json`保存音符／时长／速度段与音色类别，不携带本机路径、
历史或重复PCM，7610字节。`web-demo-example.ts`为每次访问创建独立的项目和音色引用；
逐项核对原始音符及实际音频执行参数完全一致。启动时自动展开音高／时间范围，
桌面首屏可看到完整40音符。每次加载恢复这个公开示例；“新建”仍创建空白文档，
访问者的编辑只在内存中，需下载工程保存，不会自动覆盖公开示例。

本例40音符力度均为0.75、SF2力度95、音色增益0.7，无渐强。RB135仅分析音源内部
输出，遗漏了外层调度增益；RB139补查发现外层把SF2的占位PCM当成真实满幅波形，
按重叠音符估算将整曲乘0.07519（约−22.48dB）。前4秒原音源峰值0.13526被压成
0.01017。现SF2不再参与这层静态满幅估算，恢复音源输出；普通PCM／合成器仍保留
原归一化。RB140又发现WebAudio压缩器含自动补偿和峰后恢复过程，已在播放／导出
统一替换为无记忆软限幅：幅度绝对值≤0.95保持单位增益，只弯折过高采样，不压低
后续信号。无检测器、自动补偿、恢复时间或额外延迟。
没有更改用户的音符力度或音色原始采样。所有测量在离线／隐藏测试环境完成。

## 当前网页版

- 拍线统一显示，不再为小节起点额外加深；拍线比音高行线更突出。格数表示一拍的
  细分数量，改变后只显示对应细分线，绝不自动缩放或平移，桌面记住该显示状态。
  拍线间距／位置、已有音符的起点／时长完全不变；显式格数模式按指定数量绘制。
- 顶栏提供0%～400%的总试听音量，实时作用于播放、琴键和音符试听，不改工程力度
  或导出音频。超过原始音量可放大，输出端无记忆软限幅抑制过高峰值；默认100%。单独
  试音不再固定减半，与正在播放的整曲重叠时仍为两路保留余量。
- 已写入音符的试听保留该音符的逐音音量，修复试听忽略note.level、与正式播放
  不一致的问题。键盘／音色库试听仍使用默认力度；播放使用工程保存的逐音力度。

- 与桌面版共用钢琴卷帘、音符领域和声音引擎，提供点击／拖动画音符、自由移动、
  改时长、音量、声像、音色／音符组、键盘试听、播放／暂停／定位、自动跟随、
  缩放平移、撤销重做、BPM 分段／敲击定速／格数。
- 固定八种音色：钢琴、长笛、弦乐、贝斯、八音盒、底鼓、军鼓、闭镲。采样为
  GeneralUser GS 2.0.3 原录音，SpessaSynth 4.4.4 执行完整 SF2 规则。发布时实际
  裁剪为五个旋律预设加标准鼓组，原约32.3MB SF2缩减为约8.5MB；首次发声加载，
  不只是隐藏选项。99个约8.3MB WAV仅按工程保存需要加载，完整许可随站点保留。
- 总长最多64拍（默认4/4下16小节）、16个音符组、2048个音符（含隐藏音符）。
  领域存储适配器在提交前验证，失败不改当前状态。访问者的编辑草稿只在页面内存，不自动
  保存音乐；刷新／离开前提示未下载修改，刷新后重新载入公开示例。
- 打开 `.mid`／`.midi`、v2 `.rootsound`、便携 `.rsproject`，限16MiB；超长工程明确
  拒绝，原文件不改。超出八种音色时告知替代，保留音符位置；复杂踏板／弯音等
  MIDI 信息仍受桌面当前导入器的既有边界限制。
- “下载工程”嵌入使用的原始采样，去除历史并生成原生 `RootSoundWorkspace` v2
  `.rootsound`，可在桌面版继续编辑。“导出音频”离线生成24位立体声44.1kHz WAV，
  使用完整音乐，独奏选择只影响试听。浏览器只能确认下载已发起。
- 小屏做了排版适配，但首次完整交互验证基于隐藏桌面 Chromium；手机真机、Safari
  延迟／兼容性及实际听感尚未验收。无账号、云保存、追踪脚本或后端服务。

## 源码与构建

- `website/`：宣传页、顶栏和下载链接；`web/index.html`：在线编辑器入口。
- `src/workstation/app/web-demo*.ts`／CSS：网页适配和工具栏。音乐草稿使用独立内存
  素材库；没有接入桌面本机目录、用户现有歌曲或旧的编排／共创界面。
- `vite.web.config.ts`：输出 `.cache/website/play/`，相对资源路径可部署到
  `/RootSound/play/`。共享音源路径默认仍是桌面根路径，网页使用构建基址。
- `scripts/build-web-demo.mjs`：复制宣传页、编译在线编辑器、实际裁剪 SF2、复制
  八种音色的便携采样与全部许可，生成 `.cache/website/` 发布目录。

```powershell
npm run build:website
npm run test:website
node scripts/test-web-demo.mjs
```

最后一项需要本机发布缓存里的 Electron，始终隐藏且所有音频上下文为离线替身；
不观察桌面、不输入到用户窗口、不打开物理声卡。验证真实构建在网站子路径下的
绘制／撤销／播放暂停／音频导出／工程重开，并生成隔离的桌面和手机布局图片。
