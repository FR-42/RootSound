# 音色器

双击上一级目录的 **音色器.exe**。音色打磨与歌曲截取现已合并为一个工具，打开后先显示音色打磨界面。旧的 **音色打磨.exe** 已按用户要求删除，构建只生成“音色器.exe”。日常启动不需要重新构建。

## 两个界面怎样配合

1. 初始界面保留原来的音色打磨：左侧采样列表、清理与多段对照、音高校准、延音循环、钢琴／采样键盘、保存音色和导出 WAV。
2. 点击左侧采样列表底边下方的 **＋**，进入歌曲截取界面。
3. 导入歌曲、调整蓝线和 EQ 后，点击 **导出到采样栏**。工具直接把蓝线范围内的 EQ 加工结果加入左侧列表，并返回音色打磨。第一段成为主采样，后续片段追加为参考；已有主采样保持不变。
4. 再点 **＋** 继续截取。刚才的歌曲、红蓝线、缩放／平移、EQ 和剪切撤销记录仍然保留。也可点击截取界面顶栏的 **返回音色打磨**，直接返回。

传递的是独立的浮点音频快照，无需先存 WAV 再导入，不会因后来调整歌曲或 EQ 而改变已经加入的采样。采样栏沿用每段最多30秒、最多8段、最多6400万个声道采样值的范围；失败或取消保留两边内容，歌曲本身仍支持超过10分钟。切换时停止当前试听，不自动开始另一边的播放。

用户确认只要求本次打开期间保留：切换页面不会清空，关闭工具会清理歌曲缓存，未保存的采样会话不会在重开时恢复。最终音色和 WAV 仍需在音色打磨界面主动保存。

## 歌曲截取界面

1. **导入**音频。WAV 使用本地解码器；MP3、FLAC、M4A/AAC、WMA 等使用 Windows 的音频解码能力，具体格式取决于本机支持。音频存入临时磁盘缓存，支持超过 10 分钟的文件。
2. 拖动两条蓝线选循环范围，拖动红线定位。两条蓝线可互相越过，不固定为起点或终点；取它们之间的时间作为选区。**▶** 播放／暂停，**■** 暂停并回到选区起点。播放中拖动蓝线不暂停、不反复定位，红线继续前进；只有红线碰到新的边界时才回到当前选区起点循环。重合时没有可播放或导出的范围，继续拉开后可继续。暂停时调整蓝线保持暂停。
3. **放大／缩小／全图**调整时间轴；也可 Shift＋滚轮缩放、滚轮平移、拖动底部滚动条。Shift 拖动可微调标记。
4. **剪切**移除当前片段蓝线外的内容，将保留内容作为完整的新片段，蓝线重置到两端。可**撤销剪切**。不会修改原始文件。
5. 调整下方 **EQ · 频率 → 强弱**。它直接复用精细音色生成器的原编辑器、样式、曲线及滤波器生成算法：最多 10 个点、点坐标和曲率、缩放平移、混合、撤销／重做。初始为平直曲线，保持导入音频的音色。蓝色曲线是频率增益；试听时的紫色叠图显示 EQ 后音频的实际频谱，暂停后保留。
6. **导出到采样栏**只取蓝线之间的音频，包含当前 EQ 加工结果，保留采样率和声道。加入成功后返回音色打磨，歌曲不被移除。

歌曲导入记住上一次成功使用的目录。原歌曲只读，保存音色或 WAV 时同时保护歌曲原件及其文件别名。音色打磨的处理、演奏设置和文件格式见[详细说明](../timbre-lab/README.md)。

## 实现与验证

歌曲解码 → 不可变剪切区域 → EQ 加工 → 蓝线选区 → 独立采样快照 → 音色打磨。歌曲读写和 EQ 使用固定大小缓冲区，只有已验证长度的短采样传入内存；后续效果可继续接入 `IAudioFrameSource` 处理链。两个嵌入页面由同一个窗口持有，不在切换时销毁重建。

EQ 视图和 DSP 在构建时链接 `../spectral-forge/web/` 的原文件，不维护另一份编辑器。原 DSP 在 worker 中生成最小相位 FIR；原生重叠保留 FFT 卷积支持流式播放和任意定位。试听和导出采用同一处理器，导出等待最新 EQ 生效。

```powershell
.\experiments\music-workflow\Build-ToneProcessor.ps1 -Test
```

检查包括：12 分 01 秒歌曲、多格式解码、EQ实际采样值及原算法比对，以及首段／后续追加、连续截取、反复导航、状态保留、独立快照、满栏拒绝、取消和关闭清理。原音色打磨79组回归仍运行，保留已有底层 WAV 导出检查。测试使用合成音频、隐藏 WebView2 和模拟播放对象，不显示用户窗口或使用实际声卡。

旧的 `Build-TimbreLab.ps1` 和“构建并打开音色打磨.bat”仍转交同一构建脚本，只生成并打开“音色器.exe”，不再生成旧 EXE。
