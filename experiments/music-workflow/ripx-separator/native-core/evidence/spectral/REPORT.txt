API:
  native_configuration(sample_rate) -> {sample_rate,base_window,hop}
  iter_pcm_spectral_frames(read_pcm, sample_count=..., sample_rate=...,
                           start_frame=0, stop_frame=None)
    read_pcm(start,count) returns exactly count finite mono native-unit samples.
    Each record includes frame_index, sample_index, time_seconds, windows and
    peaks. Convert each SpectralPeak with dataclasses.asdict for JSON.
    Last spectra at each resolution are reused; input reads are bounded to 2N.

  326510 passes 528f50 output then mirrors conjugates without a scaling stage;
