# 采样编辑

双击上一级目录的 **采样编辑.exe**。这个工具用于把一段音乐里的声音截成采样，独立于蓝牙录音和主工作站。

1. **导入…**：在系统文件窗口选择音乐。常见 WAV、MP3、FLAC、M4A/AAC、WMA 等由文件读取或 Windows 解码；其他格式是否可用取决于系统解码器。不支持或取消导入时保留当前内容，原文件不改。
2. 中间默认显示**频谱**：横向是时间，纵向是频率，颜色表示声音强弱。下面的“频谱”按钮可切换成**波形**，三条线的位置保持不变。
3. **红线**是播放位置。拖动红线上端的红色手柄，或点图上的空白处定位；点击“播放 / 暂停”（空格）试听。拖动正在播放的红线时暂时暂停，松开从新位置继续。
4. **两条蓝线**是采样起止。拖动线或下端手柄选区；起点手柄向左、终点手柄向右，重合时也能重新拖开。图下显示当前位置及选区时间。
5. 按住 **Shift 拖动**，移动距离缩小为正常的十分之一。选中一条线后，左右方向键移动 10 毫秒，Shift＋方向键移动一个采样帧。
6. **Shift＋滚轮**以鼠标位置为中心左右放大/缩小时间图。普通滚轮、下方滚动条或按住鼠标中键拖动可以左右移动；“全图”恢复整首音乐。
7. **倍速**打开小面板，可在 **0.750～1.250 倍**之间以 **0.001** 调整，默认 1 倍。“1×”恢复默认。速度只影响试听，音高也会随速度变化。
8. **导出…**（Ctrl＋S）通过系统保存窗口选择位置，把两条蓝线之间的**原速**音频保存成 24 位 WAV，保留源采样率和声道。蓝线重合时不可导出。取消保存窗口或导出不丢失选区；已导出的文件不会随关闭工具而删除，也不允许覆盖导入的原文件。

导入和分析在后台进行，长音乐使用本次独立的磁盘缓存，没有主工作站短采样的时间/大小限制，仍受磁盘空间与系统解码能力限制。文件过大时导出使用 RF64。关闭工具清理自己的临时缓存，保留源音乐及导出文件。没有自动保存选区工程，关闭后再次打开需要重新导入。

修改源码后可运行上级目录的“构建并打开采样编辑.bat”；日常直接点 EXE。入口需要 `sample-editor/.builds/` 配套文件和 .NET 9 桌面运行环境，不是单文件安装包。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File experiments/music-workflow/Build-SampleEditor.ps1 -Test
```

检查使用生成的音频文件、模拟播放设备和程序自行绘制的离屏图片，不读取用户屏幕或开启真实声音设备。实际扬声器听感、拖动手感及系统文件窗口仍需亲自体验。文件解码实现参考[微软音频解码说明](https://learn.microsoft.com/en-us/windows/win32/medfound/tutorial--decoding-audio)，播放进度使用[设备播放时钟](https://learn.microsoft.com/en-us/windows/win32/api/audioclient/nf-audioclient-iaudioclock-getposition)。
