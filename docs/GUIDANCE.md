# 当前桌面操作引导

2026-11-26。当前引导由欢迎页入口、乐曲库路径限制和画布操作步骤组成，
与已撤下的旧版基础引导、分段速度引导分开。网站已撤下在线试用，不提供这些桌面引导。

欢迎页首次询问是否观看，也可以通过“引导”入口重新开始。进入引导后，先准备
《初次创作》，再由用户按高亮路径打开；准备项目不会直接切换当前编辑会话。

## 引导歌曲不再依赖演示目录

内置音乐模板位于 `src/workstation/app/templates/first-creation.json`。
它随程序界面资源一起打包，内容取自现有《初次创作》。应用层的
`guide-project.ts` 通过项目目录服务检查和创建文件：

- 记忆中的可读引导项目、或原始 ID 对应的演示项目仍存在时，复用该项目。
- 目标缺失时，在项目服务报告的默认 `project` 根目录创建独立副本，
  不创建到“演示项目”文件夹，也不补回用户删除的整个演示库。
- 同名作品保留，改用“初次创作（引导）”等可用文件名；新文件取得独立项目 ID。
- 创建后刷新乐曲库并高亮实际路径；重新进入时复用已记忆的项目。
- 写入或读取失败会显示实际错误；用户仍可用 Esc 退出引导。

该创建只在用户选择进入引导后发生。它不改变安装器的规则：已有的 `project`
目录在安装或升级时始终保持原样，包括空目录和用户删除过演示曲的目录。

## 验证入口

`tests/workstation.guide-project.test.ts` 检查模板音乐一致、复用、缺失重建、
同名作品保护和写入失败。`tests/release-host.test.mjs` 还通过真实文件服务
验证根目录落盘、用户原件保持一致、准备不切换会话及后续打开。

本次隐藏界面检查使用实际欢迎页、乐曲库、项目服务和引导模块，覆盖缺少演示目录、
同名作品、写入失败及准备过程中按 Esc；不等于整套引导手感的用户验收。
