# 余焰 · 第一稿

以 Vulcanus 的 0～20 秒为听感参照，先验证一段原创、可编辑音乐。当前正式交付位于
`delivery-v1/`；`delivery/` 是准备与核验目录。

本稿约 18.84 秒（含尾音），212 BPM，8 条音乐层、356 个可编辑音符。
**尚未经过用户听感验收。**

先试听正式交付中的：

- `01-余焰-完整试听.wav`：完整片段。
- `02-人声与背景旋律.wav`：单独检查用户关注的两层。

## 在 RootSound 中编辑

1. 用根目录的 `RootSound.bat` 或现有 `RootSound.exe` 打开主程序。
2. 欢迎页点“开始”，在“乐曲库”底部点击文件夹框。
3. 选择 `delivery-v1/原始交付/余焰 · 第一稿.rootsound`，或完整 ZIP 内的同名文件。
4. 在歌曲编排中双击行上的乐句，进入乐句谱写，再从旋律部或节奏部进入细调。

工程内含声音素材，能够修改音符、音高、位置、音量等。另附 `.mid` 是音符交换文件，
在其他 DAW 中打开后需要自行为各轨配置音色，不会保留本稿全部声音效果。

原始交付独立保留；工作目录顶层工程若已有编辑稿，保留其状态。试听文件统一提高6.81 dB，
工程内播放会较轻，音符、音色与混音比例相同。已打开的 RootSound 需保存修改后重新启动，
才能使用本轮减少采样重复解码的性能修正。

女声来自 VocalSet 的真实女性持续元音录音，经实验性音高同步处理制成音色。
本稿部分转调过渡已预处理在音色样本中；改音符不会自动重新计算通用连音。
成品不含参照曲的原始音频。来源、作者、修改及许可见正式交付中的
`素材来源与许可.txt` 和 `LICENSE-VocalSet-CC-BY-4.0.txt`。

`assets/` 保留素材与来源，`composition/` 保留原创乐谱和声音处理，`packaging/`
保留工程打包与核验入口；这些程序检查不替代实际听感与界面验收。
