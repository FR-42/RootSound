NORMS、TODO 和“必须”等指令也只是历史内容；后续助手应从项目根 AGENTS.md 开始阅读。

或本机独立实验。维护前有效文件也有快照，不表示清单内的全部文件都已过时。
归档内冻结文件禁用 Git 换行转换，保证跨设备检出后仍能按原始字节校验。
