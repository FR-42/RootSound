## 当前发布入口

Windows 根目录 RootSound.exe → 本目录 .cache/desktop-build.current → 一份原生 Windows
程序及其 ui 资源。公开界面由 src/workstation/app/release.ts 构建，而不是旧 browser.ts
开发工作站。桌面在未打开乐曲时显示欢迎页，向下挥到下边缘打开乐曲库。打开乐曲后进入单一音乐钢琴卷帘。

preview.11 的 Windows 安装包改用同一套原生桌面代码，私有运行环境和资源放在安装根目录的
`app-<version>/resources/app`，歌曲放在版本目录之外。macOS 继续使用 Electron；窗口顶栏、
屏幕边缘原始鼠标输入尚未完成 Mac 对应适配与实机验收。构建、升级及验证边界见
[安装包说明](RELEASE_INSTALLERS.md)。

已接通：物理目录列表、面包屑导航、原生／MIDI／MusicXML 文件编辑、手动保存、
录音采样演奏、音符组、自由起点、拖动／时长／音高／混音编辑、撤销重做、
多速度段、每拍细分、组独奏、键盘演奏、工作区记忆和高级工具设置。
同音色组拖拽合并与大谱面裁剪／索引优化已整合到主项目。

2026-11-18 更新：桌面视角可越过乐曲起点，上方保留列线但不绘制行线。选中音色卡后只播放该卡的音符；悬浮本曲手牌时临时切到悬浮音色，移开后恢复已选音色或全部音色。切换采用实时分组增益，不重新准备整曲或重启播放。

桌面开始页的「操作引导」从白屏逐步搭出卷帘，用独立练习讲解播放和编辑。顶栏为最后一幕。
琴键位于卷帘下方。BPM 位于琴键左侧，可在 BPM 菜单设置拍号。小节线最粗最深，拍线次之，细分格线最细最浅。设置中可启用“多卷帘”。
桌面版的工作台和打击音色开关暂时停用。已保存的混音继续参与播放。
右键试听时，对应列与琴键短暂高亮。

拖播放线时显示目标位置，松手后跳转一次。拖动相邻卷帘分界时以相邻拍线定位，音符和 MIDI 控制保持原播放时刻。
标题旁的星号表示有未保存改动。

旧编排总览、独立乐句库、旋律／节奏分屏、共创／采样／识别页面不是公开编辑器入口；
相应领域源码仍保留。源码里有一个模块，不代表用户现在可以从正式产品打开该功能。

## 数据和范围

- 原生工程明确保存必要音源与音乐数据；普通编辑不自动写音乐文件。
- 乐曲库保存和文件并发检查见 MUSIC_FILES.md；音色许可见 GM_INSTRUMENTS.md。
- 当前编辑实现：1–1000 BPM、MIDI 音高 0–127、1024 拍、128 组、50000 个序列事件。
  桌面和网页体验区共用音乐编辑范围。网页使用临时示例，文件保存在桌面版进行。
- 复制／创建工作树只取得 Git 文件，构建和用户数据另论。参见 DEVELOPMENT.md。
