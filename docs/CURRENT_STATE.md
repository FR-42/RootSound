## 当前发布入口

Windows 根目录 RootSound.exe → 本目录 .cache/desktop-build.current → 一份原生 Windows
程序及其 ui 资源。公开界面由 src/workstation/app/release.ts 构建，而不是旧 browser.ts
开发工作站。欢迎、乐曲库和单一音乐钢琴卷帘是当前路径。

已接通：物理文件夹乐曲库、分页与键盘翻页、原生／MIDI／MusicXML 文件编辑、手动保存、
WAV 导出、完整 SF2 演奏、音符组、自由起点、拖动／时长／音高／混音编辑、撤销重做、
多速度段、每拍细分、组独奏、键盘演奏、工作区记忆和高级工具设置。
同音色组拖拽合并与大谱面裁剪／索引优化已整合到主项目。

桌面开始页的「操作引导」从白屏逐步搭出卷帘，用独立练习讲解播放和编辑。顶栏为最后一幕。
单卷帘模式在琴键左边显示 BPM，可在 BPM 菜单设置小节数。设置中可启用“分段调整速度”。

拖播放头时显示目标位置，松手后跳转一次。拖动相邻卷帘分界时以相邻拍线定位，音符和 MIDI 控制保持原播放时刻。
标题旁的星号表示有未保存改动。

旧编排总览、独立乐句库、旋律／节奏分屏、共创／采样／识别页面不是公开编辑器入口；
相应领域／兼容源码仍保留。源码里有一个模块，不代表用户现在可以从正式产品打开该功能。

## 数据和范围

- 原生工程明确保存必要音源与音乐数据；普通编辑不自动写音乐文件。
- 原格式保存、转换损失和外部文件并发检查见 MUSIC_FILES.md；音色许可见 GM_INSTRUMENTS.md。
- 当前编辑实现：1–1000 BPM、MIDI 音高 0–127、1024 拍、128 组、50000 个序列事件。
  桌面和网页共用音乐编辑范围。网页保存由浏览器发起下载。
- 复制／创建工作树只取得 Git 文件，构建和用户数据另论。参见 DEVELOPMENT.md。
