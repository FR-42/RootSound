# 内置 GM 音色

当前音色库提供 **128 种 GM 乐器 + 47 种标准打击音**，按键盘、拨弦、弦乐、木管、
铜管、低音、打击、电子、人声分类。音色卡悬停可查看 GM 编号（界面 1–128，MIDI
文件内部为 0–127），搜索可用中文名称或“GM 编号”。新工程自带完整目录；旧工程
首次打开补充新增条目，已经删除的旧默认音色不恢复。后续删除也不会重新生成。

在欢迎页点击“开始”，再点击乐曲库中的文件夹框，可打开 `.mid` 或 `.midi`。
各乐器和第 10 通道鼓组映射到对应采样，随后在钢琴卷帘中编辑，手动保存为
`.rootsound` 工程。MIDI 本身不包含录音，无法保证与作者使用的原音源听起来完全一样。

## 声音来源与大小

- 来源：S. Christian Collins 的 [GeneralUser GS](https://www.schristiancollins.com/generaluser.php)
  2.0.3，固定官方仓库提交 `684543d5e5efaef08d02be50dcda8d552478fa60`。
- 保存原始 16 位 PCM，保留音区、力度区、调音、循环与音量包络；匹配的多层采样
  同时播放。没有用 SpectralForge 或振荡器重新模拟这些乐器。GM 本身包含电子音色
  和音效，这些条目保留音源原有录音，不宣称全部来自原声乐器现场录制。
- 958 个独立 WAV，共 37,043,494 字节；另附 32,319,396 字节的原始 SF2。
  连目录与许可约 72.7 MB（69.3 MiB），低于用户要求的 1 GB。只在使用时加载。
- 明确保存工程时，使用中的音色收录全部音区／力度区采样；可跨设备离线编辑，
  重复录音按身份去重，不将整套 175 种音色的音频预先塞进空工程。
- 完整许可和作者对历史采样来源的说明保留于
  `public/instruments/generaluser-gs-2.0.3/LICENSE.txt`；来源摘要见同目录
  `CREDITS.txt`、`PROVENANCE.json`。

## 完整 SoundFont 播放（RB125）

新版桌面播放与 WAV 导出使用 Apache-2.0 许可的
[spessasynth_core 4.4.4](https://github.com/spessasus/spessasynth_core)，直接执行原始 SF2 的
生成器和调制器：多层／力度区、调音、循环模式、滤波器、音量及调制包络、LFO、
颤音／振幅变化、声像以及默认混响／合唱。原始采样不变，没有改为振荡器模仿乐器。

音色模块只提交薄的声音计划，所有实际 DSP 仍在全局声音运行模块完成。一条音频流
共享一个后台引擎，按音频块生成，不为整曲每个音符预生成长 PCM；解析后的音源在
同一音频上下文中共享。暂停续播、实时更新和从中段播放重建存活音符；结束的音符
不重放。跳转恢复存在一个调制控制块量级的数值差别，不宣称任意跳转逐样本相等。

内置完整规则随 RootSound 的固定版本音源提供，不依赖远程服务或第三方插件。
`.rootsound` 仍在明确保存时收录用到的全部原始采样，供工程保管与旧 PCM 通道使用。
旧 PCM 执行路径保留用于兼容／无 AudioWorklet 环境，它不等同于完整 SF2 内核。
发布资源含原始 SF2 和全部相关许可。桌面 CSP 仅额外允许 WebAssembly 编译，
没有开启 JavaScript 的 `unsafe-eval`。

## 精度边界

GM 规定编号与类别，[不规定统一的声音特征](https://midi.org/general-midi-level-1)。
这套通用库用于完整覆盖与便捷编辑，不能等同于每种乐器的独立大型录音库。
完整内核修复的是现有音源规则的还原度，不会增加录音细节、额外演奏法或自动连奏。
这也不表示 MIDI 文件中所有控制器／踏板／弯音自动化都已经导入为可编辑数据；导入
范围与音源执行能力是不同的边界。专业真实感、物理设备延迟仍需要实际试听验收。

## 维护与验证

`python scripts/expand-gm-catalog.py` 幂等生成完整目录并保留原有 53 个入口身份。
`python scripts/build-sampled-instruments.py --verify` 从固定 SF2 重新提取并只读核对
全部 958 个 WAV、原始 SF2 和音区目录；不打开音频设备，不读取用户音乐工程。
去掉 `--verify` 才会重建发布资源。原始 SF2 位于本机 `.cache/instrument-bank-source/`，
重新准备来源时应核对 `PROVENANCE.json` 中的 SHA-256。

`npm run test:music` 包含完整 128 编号及 47 打击音的生成 MIDI 导入、可编辑文档、
实际 PCM 准备测试。声音运行测试另检查多层同步、混音增益与离线 WAV 输出。

## BPM 与音符时值（RB125）

当前界面改 BPM 时保持音符的音乐长度，实际开始时间和持续秒数随速度变化。例如
120 BPM 持续一拍为 0.5 秒，240 BPM 为 0.25 秒；音高不变。旧工程原先按秒保存的
长度也参加换算，多段卷帘及跨段长音保留完整拍数。隐藏音符随所属卷帘换算，仍可
通过恢复卷帘边界重新显示。改速是可撤销的编辑，仍只在明确保存后写盘。
