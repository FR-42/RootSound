# 简乐

面向音游曲及周边曲风爱好者的音乐创作软件，目标是让爱好者快速上手，做出满意的音乐。

[在线体验](https://fr-42.github.io/RootSound/) · [下载 Windows / Mac 版](https://github.com/FR-42/RootSound/releases)

## 简单上手

- 几乎没有任何术语
- 仿直觉设计
- 非专业人士也能快速上手

> 来制作您的专属音乐吧！
