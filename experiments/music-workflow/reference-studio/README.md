## 先试这几步

1. 点击 **播放**，在 **原曲 / 我的版本** 之间切换。同一条时间线继续播放，不从头开始。
2. 点 **听原曲分层**，左边选一层 **独听**，听它承担的作用；取消独听，比较其他层怎样配合。
   这三层来自本机模型估计，可能相互混入声音。点 **回到重建** 继续改写。
3. 选中旋律层，在右边直接移动、增删或拉长音符。下面的力度条可拖动。
4. 试着调整 **明亮、渐暗/渐亮、回声**，听同一段旋律怎样变化。编辑时会切到“我的版本”。
5. **保存**，选一个位置，得到可以继续编辑的 `.rscase`；**导出我的版本**得到普通 WAV。

只需要先回答一件事：能否听出一个变化的来由，并主动做出自己喜欢的变化。
“案例说明”保留完整的来源和分析限制；选中层下面只显示该层的作用与来源。

## 本次研究的范围

使用 `D:\Sound\temp\music\Vulcanus.wav` 中约 **25.345–34.402 秒**，约9.057秒。
48 kHz双声道原曲片段按原样内嵌；用暂估212 BPM、4/4拍组织为8小节。
速度与节拍归属是分析估计，不是获得了作者的工程参数。

当前默认草稿包含5层、129个可编辑音符：低频鼓击、高频节奏、旋律轮廓、上方声部和
低音轮廓。鼓声采用本机模型估计的短采样，其余由估计音符与谱包络驱动重新合成。
**不是原始分轨，也没有完成准确扒谱或听感还原**。高音可能把倍频识别为独立音符，
低音归属仍有歧义，部分中频仍偏多。各层的说明保留这些不确定性，用户可以修改。
用数据验证了时间、频谱和音符确实可编辑；实际相似程度需要听辨，不能用测试通过代替。

“声音观察”是同一片段的辅助案例，含模型估计的鼓与打击、低音、旋律与背景三个
完整音频层；类人声输出能量很低，未列入。每层只用一个长音符触发整段声音，
可独听、静音、调整音量，**这些长音符不是原曲乐谱**。这份案例用于观察实际声音的
配合；默认重建案例用于修改音符。两者基准都保留，修改另存自己的版本。

本轮没有把音频上传到网络，也没有修改原曲或该目录下的其他歌曲。
该目录由用户指定为自己的歌曲目录；Vulcanus案例准备只使用Vulcanus，手机录音试验范围另见上文。

## 编辑与试听

- 原曲和重建共享一个播放器与输出设备时钟。暂停、继续、定位、循环都作用于同一位置。
  图上的位置对应原曲所选片段；界面同时显示原曲时间范围。
- 每层有静音、独听和音量。独听只影响试听；音符、音量、音色和声音变化保存在工程里。
- 右侧可切换钢琴卷帘和步进，两者共用音符。钢琴窗覆盖完整MIDI音域，滚动浏览；
  点已有音符主体删除，拖动移动、右缘改长，Shift精调，Shift/ Ctrl+滚轮缩放。
  “全段”恢复时间范围，撤销/重做支持连续探索。
- 音符力度条跟随钢琴窗口缩放；点音名和添加音符可以预听。琴键预听使用当前音色的
  原音高、起落和通道音量；整句播放才能听到本层渐变和回声。
- **明亮**控制低通过滤的基准频率；**渐亮/渐暗**控制整段中的频率变化方向和幅度，
  零表示不变；**回声**按当前速度延迟半拍，最多三次，逐次衰减。
- 原曲/我的版本各自的“音量”用于试听比较并随工程保存；不会自动让更响的版本显得更好。
  首尾各3毫秒缓入缓出，切换/实时修改有短过渡，过大峰值做软限制。
- “换音色”接收独立实验 `.rstimbre`，原音色文件不修改。声音层可重命名。

## 保存、恢复与原件

`.rscase` 自带原曲片段、可编辑乐句、所有演奏音色、声音控制和来源说明。
重开不需要原曲文件、原音色路径、网络或 Python。需要本工具和随附的 .NET 运行条件。
这是个人实验格式，尚未定为主工作站的工程标准。

随附案例是基准，第一次保存需要另选位置；继续自己的工程时会提示覆盖，也能另存为。
WAV 导出始终输出“我的版本”的全部未静音层，忽略临时独听；是48k双声道24位PCM。
取消或失败保留原目标；原曲及其硬链接、随附基准案例受到覆盖保护。

编辑会自动保留本机恢复稿，与明确文件保存分开。启动时有恢复稿会询问是否继续；
关闭有未保存修改时可以保存、放弃或取消。被拒绝或损坏的旧恢复稿会保留，
不会扫描删除其他工程。私有目录是 `%LOCALAPPDATA%\RootSoundExperiments\ReferenceStudio\`。
