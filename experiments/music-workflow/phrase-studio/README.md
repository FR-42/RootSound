# 乐句谱写

双击上一级的 **乐句谱写.exe**。这是第四个独立流程实验，接收“音色打磨”导出的
`.rstimbre`，输出自带全部音色的 `.rsphrase` 乐句文件。完全离线，不使用主工作站资料库。

## 新建一段乐句

1. **新建乐句**，输入名称。初始工作台没有乐句；新建后出现一个占据主要区域的乐句工作台。
2. 点击工作台里的 **新建通道**。可以先建多个通道，再分别点每行左侧的 **导入音色…**，
   在系统文件窗口选择 `.rstimbre`。导入后按钮变成音色文件名，点击名称可改名；同一乐句
   内重名会追加 ` (2)`、` (3)`。右侧 **⋯** 可以重命名、更换音色或移除通道。
3. 每行选择 **步进音序器** 或 **钢琴卷帘**。默认步进，不限制乐器种类；模式切换保留所有音符。
   步进可直接在通道行点亮格子。钢琴卷帘在行内只显示简图，双击预览或点击 **详细编辑** 进入。
4. 在 **详细编辑** 中谱写，完成后点 **返回通道**。改动已经同步，无需再点“应用”。
5. 设置速度和小节数，点 **播放** 或按空格试听全部通道。默认循环；可关闭循环听一次。
   末尾释音会自然结束。**停止**回到开头；每行可静音、调音量。添加音符、点击音名会预听，
   预听不打断正在播放的整句。播放中修改会在短输出缓冲后生效。
6. **保存**，在系统文件窗口选择位置，导出 `.rsphrase`。只要存在没有导入音色的通道，
   保存就不可用；也可以通过 **⋯ → 移除通道** 去掉不用的空通道。导入了音色但尚无音符的
   通道可以保留，适合保存模板。

## 两种详细编辑

### 步进音序器

- 每小节 16 格。点击一次添加，再点一次移除；每 4 格按拍分组。
- 左上角可选步进的音高。更换音高后，其他音高的音符仍保留；可以转到钢琴卷帘统一查看。
- 每个已点亮格子下方有力度条，可拖动改变轻重。
- 滚轮或下方滚动条左右移动。通道行的紧凑步进预览用滚轮按小节翻动。
- 左右方向键选格，上下方向键改音高，Enter 切换当前格；空格交给整句播放。

### 钢琴卷帘

- 同一连续窗口覆盖 MIDI 0～127，纵向滚动查看全部音阶，不分音区。横向是时间。
- 点空白处添加音符；点已有音符的主体可移除，也可右键删除。整个音符主体都是点击区域。
- 拖动主体改变位置/音高，拖右边缘改变长度。拖动预览连续移动，松开才吸附网格。
- **Shift 拖动**细调，网格可选 `1/16` 或 `1/32`；按住 Shift 松开可按更细的时间位置落下。
- 普通滚轮纵向滚动音阶；**Shift 或 Ctrl＋滚轮**以鼠标为中心缩放时间。
  中键拖动平移，底部/右侧有滚动条，**全句**恢复全段时间。
- 点左边音名可预听。添加或拖动音符后，方向键可继续移动该音符，Delete 删除，
  Shift＋左右方向键做细调。

步进模式只操作所选音高的格子，不会清空钢琴卷帘中其他音高的内容；也不生成暗色参考音符。
**撤销/重做**和 Ctrl＋Z/Y 可恢复编辑。缩短乐句若会截掉音符，会提示先移动或删除这些音符。

## 继续已有乐句与保存

点击 **从上一个乐句开始**，在系统文件窗口选择 `.rsphrase`，直接载入全部通道、音符、
速度与内嵌音色。之后 **保存**覆盖当前文件前会弹窗提醒；若文件在外部有变化也会说明。
旁边的 **另存为**可以选择其他位置，保留原件。取消窗口或保存失败不会损坏已有文件。

文件自带浮点采样及第三个模块的原音高、起落、循环等设置；无需原 `.rstimbre` 文件才能
重新打开。原始音色不改，重命名或更换通道音色只作用于当前乐句。实验格式还不是主工作站
歌曲编排的导入接口；本轮输出是可编辑乐句文件，不是混音后的音乐音频文件。

可同时打开多个乐句，顶部页签切换；切换时停止其他乐句的试听。

## 自动保留与明确导出

完成一次点选、拖动或参数调整后，改动立即进入乐句，并在约半秒后自动保留本机稿。
这不等于已经更新你选定的 `.rsphrase` 文件；文件仍由 **保存**明确写入。页签 `*` 表示
相对上一次文件保存还有修改，底部会区分“本机保留”与“文件已保存”。

关闭整个工具会保留这些工作；下次打开先显示空工作台，点击 **恢复上次工作**继续。
关闭单个乐句时可以保存、放弃或取消。恢复稿位于
`%LOCALAPPDATA%\RootSoundExperiments\PhraseStudio\`，与主工作站资料库分开。
音色在私有恢复区缓存，音符编辑只更新小型说明文件，不反复复制整段音频。
不扫描删除其他目录、原音色或已导出文件；旧私有素材缓存暂不自动清理。

快捷键：Ctrl＋N 新建、Ctrl＋O 从已有乐句开始、Ctrl＋S 保存、Ctrl＋Shift＋S 另存为、
Ctrl＋Z/Y 撤销/重做、空格播放/暂停。文本和数字输入保留自身的键盘输入。

## 运行和检查

需要 Windows 10 2004 或更新版本、.NET 9 桌面运行环境以及 `phrase-studio/.builds/`
配套文件；这枚小 EXE 不是单文件安装包。源码修改后使用上级的 **构建并打开乐句谱写.bat**。

首版固定 4/4 拍，速度 20～300，每个乐句 1～16 小节、最多32通道/10,000音符，
内嵌采样总量最多512MiB。每个音色仍遵守第三模块的30秒/8声道范围。播放最多128个
同时发声音符，超过会说明并停止试听，乐句数据保留。这些是可调整的实验范围。

开发检查不会显示应用窗口、操控桌面或开启真实声音设备：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File experiments/music-workflow/Build-PhraseStudio.ps1 -Test
```

检查使用生成音色、模拟设备时钟、构造/布局检查和程序绘制的离屏图片。实际扬声器听感、
鼠标手感、系统文件窗口及真实屏幕显示仍需使用验收。
