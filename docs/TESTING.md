## 已确认的末尾空白行为

位置：tests/workstation.playlist-controls.test.ts，
`shelf reorder is a single durable nonmusical edit and survives restart, undo and a full project copy`。

复现：旧编排工程的两个片段在 0 秒、4 秒开始；旧计划含片段空白尾段，总长 12 秒。
另存为当前单一乐谱后，**播放事件内容和时刻相同，计划总长变成 8 秒**。此前完整计划比较因此失败。
用户随后明确确认空白时长可以缩短、不影响项目；产品功能源码无须为这项差异修改。

测试现在逐项比较序列类型、版本和全部声音事件，并确认该用例从 12 秒缩为 8 秒后仍覆盖
最后一个音符及其释放尾音。该变化只接受末尾空白缩短，不放宽音符丢失、移位、时长或声音参数改变。
对应用户确认已记录在 governance/DECISIONS.md 和中文对应文件。
