# Windows 桌面使用说明

更新：2026-10-23。当前提供音色制作、乐句谱写、歌曲编排、首版后期、实体栏拖放、采样与哼唱识别、WAV 和工程文件。灵感共创暂时隐藏，优先完善核心编辑。下方共创操作仅作为暂停功能的历史说明。完整验证记录见[重建进展](REBUILD_PROGRESS.md)，本轮未操作屏幕或做真实听感、视觉验收。

## 当前创作方式

欢迎页“开始创作”进入音色制作。左侧实体栏按当前作品归属列出音色和乐句，公共起点
另列；音色拖入乐句会新增声部，乐句拖入歌曲按时间落点摆放，双击可编辑。大段介绍
已移除，音色曲线、采样波形、卷帘和时间线使用主要窗口空间。

普通保存按实际使用位置判断：单引用覆盖，多引用为当前位置创建新实体，必要祖先
同样处理；已保存状态和稿件相同位置合计一次。库内零/单引用可覆盖，多引用另存，
明确“另存”始终新建。嵌套编辑到外层保存才提交。覆盖后若上游歌曲又被保存或改动，
旧撤销会明确拒绝影响新版本；正常未冲突的历史可跨重启恢复。

歌曲“后期”可调整总音量和淡入淡出，或勾选原声对比；试听与 WAV 使用相同设置。
淡出计算包括最后的自然收音，设置随歌曲、撤销和工程文件保留。当前淡入淡出各
0–30 秒，总音量 0–100%，全局峰值保护继续生效。

## 启动、更新与退出

日常双击项目根目录的 **`RootSound.exe`**。固定入口直接选择最近一次完整构建的版本，不经过控制台、不检查源码，也不在启动时联网或编译。关闭窗口即可退出。

**`RootSound.bat` 仍可一键构建并打开。** 新取得的源码没有根 EXE 时、修改源码后自行构建时，或需要重新生成入口时使用它。首次会构建界面和桌面程序，之后源码未变且入口完整时直接打开；每次构建都会同步生成根 EXE。源码 Git 不收录这枚生成的 EXE。

当前使用真正的 Windows 窗口，内部通过 WebView2 显示本机构建界面。WebView2 是微软提供的桌面内嵌网页运行组件，不需要外部浏览器或本地网页服务。构建完成后的当前创作、试听、导出和本地保存均可离线使用。

首次构建需要已安装 Node.js 24、.NET 9 SDK 和 WebView2 Runtime，本机均已具备。首次获取前端与 NuGet 开发依赖可能需要联网；NuGet 是桌面项目获取依赖的工具。构建后的 EXE 日常入口不需要 Node.js、SDK 或 PowerShell，主程序仍需 .NET 9 桌面运行环境和 WebView2，启动器使用系统 .NET Framework。它不自动安装系统运行环境，也不在失败后切换浏览器。

构建会输出到新的 `.cache/desktop-builds/<构建编号>/`。主程序、界面和小启动器都构建完成后，原子更新根 EXE，再切换 `.cache/desktop-build.current` 中的启动目标；失败时保留此前选中的主程序。这样不会覆盖正在使用、被 Windows 占用的旧主程序。

根入口严格选择本目录下受管的构建位置，必要文件缺失或路径异常会显示明确错误。它会原样转交启动参数，包括中文和空格目录，不通过 Shell 拼接命令。根 EXE 是小启动器，不是装下整个工作站的单文件；配套的构建目录、DLL 和 `ui/` 仍需完整保留。安装包、签名、运行环境随包部署及正式便携发行版留到发布阶段单独完成。

**已有窗口继续运行旧版本。更新后先关闭使用同一资料库的旧窗口，再双击根 `RootSound.exe` 打开新版。** 新构建不改变资料库目录；启动第二个同库窗口会提示锁定，不能通过删除锁文件解决。

## 获取并保存一段采样

从顶部进入 **“采样获取”**，也可在设置中把它选为启动入口。

1. 点“导入音频…”选择文件，或点“录一段”并允许麦克风授权。录音期间可见时长和输入音量，点“完成录音”结束；最多录制 30 秒，等待授权时也可取消。
2. 完成后查看波形，给采样起名并点“听听”。波形当前只供查看，不能裁剪或调整内容。
3. 点“保存采样”加入公共素材库；以后可在本页已保存列表打开、试听。素材管理只列当前歌曲工程实际包含的采样。

**未保存的采样只在本次运行的内存中。** 切换工作区会保留已完成的这段采样，完全退出会丢失。换文件、重新录音或打开另一采样时，若尚未保存，会提供“保存后继续 / 放弃并继续 / 返回”。保存失败保留当前采样并提示重试；获取取消或失败也不替换原采样。离开本工作区会停止并取消未完成的录音，迟到的麦克风授权或加载结果不能覆盖当前内容。

导入保留原文件字节。本地支持 PCM WAV 的 8/16/24/32 位整数和 32/64 位浮点音频；其他编码由当前运行环境的解码能力决定，不保证任意格式可用。暂定上限为原文件 **16 MiB**、解码后 **120 秒、64 MiB**，不是最终产品限制。

麦克风录音当前生成单声道 32 位浮点 WAV，使用浏览器音频采集的实际时钟；程序请求关闭回声消除、降噪和自动增益，但设备及系统可能仍有处理，不能称为硬件逐位无损。Windows 宿主仅让受信本地界面的麦克风请求走正常授权流程，不绕过授权；其他来源与权限拒绝。本轮未实际启用设备录音，设备效果与兼容性待验收。

采样独立保存在素材库，没有持久编辑稿；改名再保存会产生新素材，不覆盖旧采样。完整采样编辑和系统声音录制尚未实现。下方哼唱识别另行生成使用合成音色的可编辑乐句；希望原声音本身作为乐器演奏，可用下面的音色入口。

## 让采样成为可弹奏音色

1. 完成导入或录音后点 **“用这段声音制作音色”**。它先保存原采样，再进入音色制作，失败可重试；等待时可以离开，不会迟到切走另一份声音稿。
2. 拖动波形两端选择播放范围，也可用左右方向键（Shift 加快）或输入起止秒数。原文件完整保留，范围只属于当前音色。
3. 选择原始音高；默认 A3 / 220 Hz 是起点，需要按素材调整。精确 Hz 收在展开项，自定义值不会强行改成标准音名。点低一些、原音、高一些试听一个音符，拖动起落曲线或音量即时听变化。
4. 需要长音时展开“延长声音”，启用循环并选择循环起止位置。音符先播放开头，再重复这段声音，直到收音；范围须在播放范围内。选择平稳且衔接自然的片段，当前不会自动消除接缝。
5. 点“保存”，进入乐句谱写选择这件音色，写旋律、编歌并导出 WAV 或完整工程。撤销、重做与修改一起保存在本机，关闭后仍可恢复。

未启用循环时原件播放一次，到裁切尾部或音符收音完成时结束。移调仍同时改变速度；保持时长移调、自动识别原音高、多采样键位/力度映射及独立采样音色交换文件尚未实现。`.rssound` 携带无依赖的电子音色，采样音色与原件使用 `.rsproject`。

音色只存参数和原件引用，同一原件可用于多件音色。普通当前位置修改和联合应用沿用下方规则。含采样音色的乐句进入共创后，裁切、原音高和手工包络保留，方向选择不会偷偷换掉它的声音；本地方向可以通过合成伴奏增加变化。

## 把单人哼唱变成旋律

先导入或录好一段 **30 秒以内的单人清唱或哼唱**，原采样可以尚未保存。

1. 点采样下方的 **“把哼唱变成旋律”**。它在本地后台分析，不使用 AI；可查看进度并随时取消。超过 30 秒会明确拒绝，不自动截取。
2. 点“听听识别结果”，也可点原采样的“听听”交替核对。页面显示音符数及少量识别提示；识别把握较低的音符需要特别留意，分析和试听不会保存素材。
3. 选“去细调”才保留这份乐句并直接进入编辑；连续卷帘会对准主要旋律，共创衔接暂时关闭。

确认会一起保存配套合成音色、乐句和编辑稿，原音频不被改写；失败保留结果，可重试，不重复创建同一份已确认旋律。这不替代“保存采样”：希望原录音退出后仍在，需要另外保存采样。识别出的旋律进入共创后，可继续写成歌曲、导出 WAV 或保存完整 `.rsproject`。

识别按原演唱时间保留音符起止、间隔与休止，音高保留识别得到的频率，不猜 BPM、调性或自动纠音。乐句中看到的默认 120 只是把秒换成可编辑拍数的坐标，不表示已经识别出歌曲速度。音高、起点或长短有误，可在细调中纠正；颤音和滑音目前整理成平直音符，不保留完整的连续音高曲线。

首版适合一个人的清唱或哼唱，不负责从混合歌曲分离伴奏，也不能保证多人、和弦或复杂背景中的识别准确，更不识别歌词。换采样、重新录音、离开工作区或取消分析会终止后台任务及旧试听，过时结果不能用于下一段声音。当前只有合成音频与程序化验证，真实人声的准确性、设备和界面体验仍待用户检验。

## 先听，再选一个方向（暂时隐藏的历史功能）

欢迎页点 **“开始旅途”**，或从顶部进入 **“灵感共创”**。页面明确标注“离线灵感 · 本地规则生成”，提供轻快、温柔和空灵三个方向；它们是本地规则生成的可编辑建议，不是 AI 对话或联网结果。

1. 可以直接试听三个方向，也可以在“从我的乐句继续”选一段已保存旋律，点“开始探索”或“换个起点”。旧探索稿和原旋律保留。
2. 点“听听”试听，喜欢再点“选这个”。当前正在试听的按钮可以停止或取消；试听本身不保存候选素材，选择才保留结果。
3. 结果可以再次试听，点“细调这段旋律”进入乐句工作区；保存后回到共创，用修改后的结果继续探索。“用它创作歌曲”会建立一份新歌曲并放入当前结果，原歌曲稿不被覆盖。

还有未完成的细调时，先保存或取消，再选择新方向、换起点或把结果交给歌曲。重新点击“细调这段旋律”可以回到未完成的稿件。共创的撤销、重做记录会保存，关闭重开后仍可使用，也支持 Ctrl+Z、Ctrl+Y；旧旅途可从素材管理继续。

当前规则会提供不同音色质感，并在容量允许时加入简单低音与铺底；可以使用前一步已确认的哼唱旋律，但不直接理解原录音、复杂曲风意图或个人偏好。更多表达方式、细致方向和 AI 辅助仍是后续范围。

## 从声音到歌曲

声音、乐句和歌曲分别显示，通过顶部切换。声音和乐句都可以独立试听、保存、导出，不必先建立歌曲。

1. 在“音色制作”点“新建音色”，试听并选择一个起点。调整声音组成与音量形状，改名、保存；也可选择使用录音或音频。
2. 进入“乐句谱写”，新建乐句，选择刚保存的声音。点击添加音符，拖动移动，拖右端手柄改长短；“加一个声音”可叠加另一部分。
3. 调整乐句速度、长度和落点，试听整段并保存。键盘不再分音区，上下滚动同一窗口可查看全部 96 个可用音高；初次进入对准主要旋律，同稿操作保留位置。缩短长度不会自动剪掉音符，需先移回或缩短超出的音符。
4. 进入“歌曲编排”新建歌曲，把“我的乐句”中的乐句拖到时间线。也可点击乐句卡片，接到所选轨道末尾。
5. 移动、复制或重复片段，添加轨道，调整音量、左右位置、静音和单独听，最后点“保存工程…”选择位置保存 `.rsproject`。

歌曲默认**各乐句保留原速**。例如两个乐句各为 90 和 120 拍/分钟，默认仍各以自己的速度播放；也可在“乐句速度”里改为全部跟随歌曲速度。源乐句的音符位置与速度不因这项选择被改写。时间线刻度仍按歌曲速度显示，所以保留原速的不同乐句可以占据不同宽度。

乐句和歌曲引用公共库中已保存的素材。普通复制保留这些引用；普通修改则只影响进入编辑时的当前使用位置。系统在保存时自动分离必要的音色和乐句，不要求先手工另存，也不会覆盖其他作品采用的原素材。

“我的声音”“我的乐句”“我的歌曲”可返回已有作品；“素材管理”只看当前歌曲工程。编辑稿会在本机持续保留，供关闭后恢复；这不代表已经把 `.rsproject` 写到用户选择的位置。写入失败明确提示，不把失败当作已保存。

## 自由制作电子音色

“新建音色”在普通编辑和当前处细调时都可见。先浏览或试听，不会结束原细调；真正选择新建后，当前处还有修改时才询问保存或放弃。独立音色的原稿保留，可从“打开音色”继续。

当前提供 12 个可编辑起点，覆盖旋律、低音、铺底、打击和音效。“声音组成”可叠加最多四个声源，选圆波、三角波、锯齿波、方波或噪声，独立开关与调音量。音高和微调在每个声源下展开。它们是电子声音起点，不是真实钢琴或吉他采样库。

直接拖动音量曲线可改变起音、回落、保持、收音，下方滑杆显示数值。声音明暗提供柔化高音、削去低音或突出一段；“音高变化”用于音头上扬或下落。播放中修改会接着当前进度反馈，松手才记一次修改，取消恢复原参数。

点下方琴键试音，电脑键盘 A W S E D F T G Y H U J K 对应同一组音高；输入文字时不抢键。空格控制主试听，Ctrl+S 保存，撤销/重做可跨关闭恢复。首次打开旧配方只展示等价控制，不自动改写声音。常驻仍只有一个保存，更多操作放在“⋯”，文件操作收在顶部“文件”。

## 调整这一处，或应用到其他位置

歌曲中同一段副歌出现三次，想只改第二次：

1. 双击第二个片段，或选中后点“编辑乐句”；键盘 Enter 也可以打开。
2. 在乐句内移动音符；如果要改变某条声音，点旁边的“调整声音”。顶部显示完整进入路径和返回入口。
3. 保存声音，返回乐句；保存乐句，返回歌曲。系统只让第二处采用新结果，第一次、第三次和其他歌曲继续使用原内容。

音色制作只突出一个 **“保存”**，**“⋯”** 中按需提供“另存副本”和“应用到其他位置…”。新音色没有这些次级操作时不显示“⋯”；从当前使用位置进入细调时不提供另存。采样音色同样把其他位置操作收进“⋯”。Ctrl+S 与主保存使用同一操作。

要一起改变其他位置，在音色的“⋯”或乐句页面选择 **“应用到其他位置…”**，按作品展开并勾选具体位置；当前处始终选中。也可右键歌曲片段或乐句的声音，选择“联合修改…”先选范围再调整。未选位置保持原样，取消位置选择不提交修改。

如果是在歌曲→乐句→声音的嵌套编辑中选择联合位置，声音保存先回到父乐句，这些联合选择随父乐句暂存；直到父乐句保存，才一并应用到外部位置。取消父乐句不会改变其他歌曲。还有未完成的下层编辑时，需要先保存或取消下层，不让父级保存留下失效的编辑入口。

从素材库直接打开已保存的声音或乐句，没有明确的“当前这一处”，零或单引用可覆盖，多引用另存新素材，不擅自替换已有引用。歌曲主保存入口负责选择位置写出工程文件。编辑上下文内隐藏会跳到另一份稿件的“新建 / 我的乐句”等入口，可先通过顶部返回或切换素材工作区。

修改结果和引用调整一起可靠保存：源素材或选中位置后来被改变时，会拒绝旧范围的应用并保留编辑稿；写入失败不会留下只有一半位置更新的状态。

| 纠错 | Ctrl+Z 撤销；Ctrl+Shift+Z 或 Ctrl+Y 重做 | 同左 |
| 试听 | 空格或“听整段” | 空格或“听整首” |
| 保存 | 保存按钮或 Ctrl+S；当前处编辑按当前范围保存 | “保存工程…”或 Ctrl+S 选择位置，保存 `.rsproject` |

音符复制后默认在所选音符后粘贴；Ctrl 点空白可设置其他粘贴位置，界面会显示对应拍数。可以选中多个音符一起调整力度，使用“缩放”改变横向显示。切换声音部分后也可粘贴复制的音符，新音符具有独立身份。

淡色、较暗的音符属于这段乐句中的其他声音，仍会一起播放。单击它会切换到对应声音并选中这个音符，不会在下面另加音符；右键直接删除指向的那个音符，删错可撤销。

播放中拖动声音起落曲线、音量、音符或歌曲片段时，可以立即听见变化，播放位置继续前进；更换音色、调整乐句速度与力度、歌曲左右位置、静音和单独听也会即时反馈。拖动中不反复保存，松手才提交一次，取消或写入失败恢复先前内容与试听。成组移动、复制和删除可一步撤销。当前未使用系统剪贴板，音符和片段复制限于当前工作区会话，不承诺跨软件粘贴。

“落点”或“对齐”控制时间吸附，“自由”关闭吸附。显示刻度和缩放不限制原有数据精度；水平移动不把音高强行改成键盘音高。每次选中一个声音部分进行成组编辑，其他部分留作参照，单击淡色音符即可切换。

乐句和歌曲的撤销、重做按具体编辑稿保留，最多 64 步，退出再打开仍能继续使用。历史与编辑内容一起可靠保存；写入失败不推进历史，撤销后作出新修改会清除重做分支。旧资料库没有以往的历史，从更新后的操作开始积累。

按位置应用作为一次复合操作记录，撤销、重做能一起恢复相关引用调整。联合应用按当次范围整体撤销，包括当次选中并更新的外部已保存作品；这些外部作品后来又被修改时，系统会拒绝操作，避免用旧历史覆盖新创作。当前歌曲在应用之后另行保存的版本不随编辑稿撤销被倒改，它仍需要的派生声音和乐句也会保留。音色制作已有独立参数撤销；从乐句或歌曲发起的声音应用仍由对应父稿的复合历史管理。即时试听不替你覆盖共享素材。

## 保存和打开歌曲工程

在“歌曲编排”点 **“保存工程…”** 或按 **Ctrl+S**，都会打开 Windows 位置选择，把当前歌曲工程写为 `.rsproject`；空歌曲也可保存。它携带歌曲、显式保留的工程成员及其全部依赖，换到另一台运行兼容 RootSound 的设备，甚至空素材库、断网环境，也能打开并继续编辑。无需从原设备另找素材。

欢迎页或歌曲顶部的 **“打开工程…”** 可选择文件。导入前检查格式版本、素材类型和全部引用；缺少依赖、存在循环或不支持的内容会明确拒绝。成功后一次加入全新的歌曲、乐句和音色身份，不覆盖同名作品，原编辑稿仍保留。取消文件选择、校验失败或写入失败都不会丢弃原创作。

保存采用点击时的工程快照，不要求先保存一份内部歌曲。还有这首歌的乐句或声音正在细调时，会提示先完成或取消，避免只保存旧引用。本机编辑稿持续保留用于恢复；后续修改不会自动更新已经写出的文件，需要再次“保存工程…”。取消文件选择不报保存成功，写入失败提示原因并保留创作。

工程文件包含当前歌曲及显式成员的完整依赖。在素材管理中明确另存的副本，即使尚未放入编排，也是当前工程成员。没有附加成员时使用 v1，有成员时使用 v2，当前可读取两版；缺失、循环或未属于歌曲/成员依赖的孤立内容会被拒绝。其他歌曲、旧保存、撤销历史、未完成编辑上下文和本机偏好不随文件搬运。当前支持基础合成与采样音色，收齐原始采样；暂定上限为 **32 MiB、8192 份内容（包括歌曲）**。PCM WAV 使用内置解码，其他压缩编码仍需目标环境有相应能力。Windows 实际写入成功才提示文件已保存，浏览器验证版只提示已发起下载。

可用三步体验这项功能：

1. 打开或新建一首歌曲，点“保存工程…”或 Ctrl+S，选择位置保存 `.rsproject`。
2. 在另一台运行兼容 RootSound 的设备或独立空素材库中，选择“打开工程…”。
3. 修改歌曲后再次保存工程，确认可以继续编辑并更新文件。

## 导出可播放音频

在声音、乐句或歌曲工作区选择“导出音频”，然后点击“开始导出”。程序实际离线生成 WAV，即不需要一边播放一边录音；画面显示生成进度，生成期间可以取消。

当前界面输出 **48 kHz、24 位、双声道 WAV**：每秒 48,000 次采样、每个采样用 24 位数值保存，具有左右两个声道。包含作品范围、静默与自然尾音，使用与试听相同的发声和音量变化处理。

生成完成后打开 Windows 保存对话框。取消文件选择不会改动创作，也不会报告文件已保存；写入失败保留旧文件并提示重试。覆盖已有 WAV 时由系统对话框提示，成功替换会保留相邻 `.bak`。当前 WAV 最大 256 MiB；歌曲试听与导出最长 10 分钟，超过本阶段范围会明确报错。

WAV 是给播放器使用的音频，不包含可继续编辑的音符、轨道和素材关系，不能代替 `.rsproject` 工程文件。浏览器验证版只能提示“已发起下载”，需在浏览器中确认是否完成。

## 素材和启动设置

顶部“素材”或“素材管理”只显示当前歌曲工程的当前歌曲、乐句、音色与采样，可分类、搜索、试听和编辑。同一实体的已保存状态与有效编辑稿只显示一次，优先展示当前修改；只为旧保存和撤销保管的内容、其他歌曲、公共起点和暂时隐藏的共创均不列入。没有当前歌曲时，显示空状态；独立音色或乐句仍可从各自工作区打开。

“使用关系”只追踪本曲当前实体之间的直接或间接引用，也显示它使用的素材。“另存副本”生成本曲新成员，仍引用原有下层素材；即使暂未编排也会显示并随工程文件保存。它不会同时复制整套声音；歌曲内复制或重复片段仍是在不同位置使用同一乐句。之后修改某一处时，程序再按实际引用数决定覆盖或分离。实体栏也使用当前工程范围，公共起点只在其“素材库”中另列。

顶部“设置”可以关闭欢迎页，并选择采样获取、音色、乐句、歌曲、素材或上次工作区；旧共创入口映射到音色制作。欢迎页“继续创作”回到上次位置，“直接进入创作”采用配置入口。设置不移动作品，写入失败保留旧设置。

## 单个声音文件

音色顶部“文件 → 导出音色…”把当前名称和全部电子合成参数写为 `.rssound`。旧配方输出 v1，新合成结构输出 v2，当前版本均可读取；它包含未完成稿的当前参数，不代替应用到当前位置或工程保存，也不改其他作品的引用。

“打开声音文件”验证格式与所有参数，再加入独立新编辑稿。已有声音、同名声音和引用保持不变，不继承来源设备内部身份；取消、损坏、不支持版本或写入失败均不会替换当前资料库。

当前 `.rssound` 携带一个无外部依赖的电子音色，**不含乐句或歌曲，不是可播放音频，也不是完整工程格式**。要搬运当前整首歌曲及所用声音，包括采样音色与原件，请使用 `.rsproject`。

## 本地数据和恢复

默认资料目录是 `%LOCALAPPDATA%\RootSound`，可粘贴到 Windows 资源管理器地址栏打开。

| 文件或目录 | 用途 |
| --- | --- |
| `materials.json` | 已保存声音、采样、乐句、歌曲、独立编辑稿、灵感旅途记录、位置编辑上下文及持久撤销重做历史；不含未保存采样 |
| `materials.json.bak` | 上一次写入前的版本；首次写入前没有此文件 |
| `materials.lock` | 同库实例锁；文件存在本身不代表程序正在运行 |
| `webview/` | 内嵌界面运行资料，包括本机启动显示偏好 |

正式资料先写入同目录临时文件，再可靠替换；读取失败、坏文件、外部修改冲突或保存失败会明确提示，不会以空库覆盖。某份音乐内容格式不支持时保留原稿，仍可打开其他正常作品；整个资料库结构损坏则停止读取。

原生资料库当前上限为 128 MiB，单个 `.rsproject` 文件上限仍为 32 MiB；两者都是可调整的当前实现限制。

`.bak` 每次成功写入时更新，是上一版副本，不是无限历史。手工恢复前先关闭所有 RootSound 窗口，复制整个资料目录留档，再用确认可用的备份复制替换 `materials.json`。不要通过删除 `materials.lock` 处理第二实例提示，关闭已打开程序会释放真正的文件锁。

## 从浏览器搬入创作

浏览器验证版通过 `npm run dev` 启动，数据属于当时的浏览器、地址和端口；桌面不自动读取或搬运。

1. 在原浏览器、相同地址和端口打开验证版。
2. 从“我的声音”打开声音或编辑稿，点击“保存声音文件”。
3. 确认浏览器实际下载了 `.rssound`，再到桌面打开该文件。
4. 如需加入已保存声音，再点击“保存声音”。

多个声音可逐个操作；若已有歌曲，可在浏览器“歌曲编排”保存 `.rsproject`，确认下载完成后在桌面“打开工程…”，一次搬入该歌曲及其全部当前依赖。完成前保留原浏览器数据。当前仍没有独立乐句文件或整库迁移功能。
