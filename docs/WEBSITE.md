# 简乐网站与在线编曲

公开地址：<https://fr-42.github.io/RootSound/>。保留简乐顶栏、GitHub 图标链接和
Windows／Mac 下载卡片，下方内容按用户要求加入真正可操作的缩减版钢琴卷帘。

## 操作演示

钢琴卷帘上方的浅灰「操作演示」区域显示一叠动图书页，白色「动手试试」区域承载真实编辑器，可通过
<https://fr-42.github.io/RootSound/#guide> 定位。六页聚焦添加音色、BPM／敲击定速、
每拍格数、横竖缩放合页、选中／添加／取消选中后拖动画布、延长／新建卷帘。页面只有短标题、一句提示、小圆点和页码，没有
视频播放器、下载视频或长篇步骤。使用左右方向键、边缘小箭头、圆点或横向轻扫
翻页；不会自动切页。翻页采用轻微立体旋转、位移和淡出，420ms结束，连续快翻
只保留当前页与退出页，避免堆积或旧图片覆盖新页。

- 主展示为1920×1080无损循环动态WebP、30fps，另有静态封面；不再生成重复的GIF。
  演示与编辑器同宽、16:9；实际从2400×1240双倍像素界面生成，避免放大低清截图。首次只加载当前页，
  图片解码后再翻页，避免空白闪烁。离开视口／后台标签时切回静态封面；可用小图标
  停止或重启动图。系统偏好减少动态时默认静态、翻页无动画，仍可手动启动动图。
- 横向缩放：Ctrl＋Shift＋滚轮；竖向缩放：Ctrl＋滚轮。Mac也支持⌘。
  格数页只讲同样一拍分成2／3／4格，按用户最新要求去掉拍号说明。
  BPM页左边调速、右边实际卷帘，时间缩放始终固定256px/秒，并标注相邻拍线距离、
  每拍秒数；敲击定速实际发送空格键，按500ms节奏得到120BPM。不播放声音。
  添加音色页在卷帘按下后直接向下拖写长音符，不再先松开再拉尾端。新增一页演示
  下拉卷帘底边增加拍数（16→20），下方＋添加独立速度卷帘；断言长度和卷帘数量改变。
- 生成器 `node scripts/render-operation-guides.mjs` 在始终隐藏的离屏真实编辑器中
  生成302个双倍像素操作状态，再用 `python scripts/encode-operation-guides.py` 合成六页动图，
  不再产出视频／音轨／字幕文件。仅教学构建暴露模型用于自建数据和实际改速／缩放
  断言，正式网页没有此入口。不拍用户桌面、不使用真实文件选择器／声卡，不读歌曲。
  需要本机Electron缓存、Pillow及Windows微软雅黑字体；无需FFmpeg。
- `website/guides/` 只保留六页WebP／封面及清单；生成器和网站构建都清除旧教程
  素材，旧视频不进入发布目录。页面脚本／样式／媒体带v6参数，避免旧版本缓存。
  原始操作帧和验证证据在.test-output/rb136/，不公开上传。

网页底部展示用户指定的特别鸣谢，README保留用户文案并整理标题／要点／体验下载链接。

## 播放结束

本地和网页共用播放规则：按最后一个可播放音符的实际持续时间，找到它结束时所在
小节的末端，归零并暂停，不等待之后的空小节。跨BPM卷帘／长音／弱起也按原时钟
计算，隐藏音符不延长试听。手动定位到最后音符之后的空白区时，临时允许播放到
完整编辑长度；停止或定位回音乐区域后恢复自动结束。编辑中重新计算结束点，
播放头逐帧移动只读取缓存，不反复扫描全部音符。只影响试听，不改工程或导出长度。

## 默认示例

用户提供当前Chrome页面下载的工程，含40个钢琴音符、148BPM。原文件只读保留；
`website/examples/starter.json`保存音符／时长／速度段与音色类别，不携带本机路径、
历史或重复PCM，7610字节。`web-demo-example.ts`为每次访问创建独立的项目和音色引用；
逐项核对原始音符及实际音频执行参数完全一致。启动时自动展开音高／时间范围，
桌面首屏可看到完整40音符。每次加载恢复这个公开示例；“新建”仍创建空白文档，
访问者的编辑只在内存中，需下载工程保存，不会自动覆盖公开示例。

用户报告同一次播放开头较小。检查本例40音符力度均为0.75、SF2力度95、音色增益0.7，
没有渐强配置；同音同力度重复测量振幅差<0.6%，未发现源引擎自动升音量。
原例0.25秒窗口中较强段比开头约高2.4dB，符合音高采样／叠音及余音的差异。
这是离线信号分析，不能代替用户Chrome／声卡实听；未据此更改音乐动态或公共DSP。

## 当前网页版

- 与桌面版共用钢琴卷帘、音符领域和声音引擎，提供点击／拖动画音符、自由移动、
  改时长、音量、声像、音色／音符组、键盘试听、播放／暂停／定位、自动跟随、
  缩放平移、撤销重做、BPM 分段／敲击定速／格数。
- 固定八种音色：钢琴、长笛、弦乐、贝斯、八音盒、底鼓、军鼓、闭镲。采样为
  GeneralUser GS 2.0.3 原录音，SpessaSynth 4.4.4 执行完整 SF2 规则。发布时实际
  裁剪为五个旋律预设加标准鼓组，原约32.3MB SF2缩减为约8.5MB；首次发声加载，
  不只是隐藏选项。99个约8.3MB WAV仅按工程保存需要加载，完整许可随站点保留。
- 总长最多64拍（默认4/4下16小节）、16个音符组、2048个音符（含隐藏音符）。
  领域存储适配器在提交前验证，失败不改当前状态。访问者的编辑草稿只在页面内存，不自动
  保存音乐；刷新／离开前提示未下载修改，刷新后重新载入公开示例。
- 打开 `.mid`／`.midi`、v2 `.rootsound`、便携 `.rsproject`，限16MiB；超长工程明确
  拒绝，原文件不改。超出八种音色时告知替代，保留音符位置；复杂踏板／弯音等
  MIDI 信息仍受桌面当前导入器的既有边界限制。
- “下载工程”嵌入使用的原始采样，去除历史并生成原生 `RootSoundWorkspace` v2
  `.rootsound`，可在桌面版继续编辑。“导出音频”离线生成24位立体声44.1kHz WAV，
  使用完整音乐，独奏选择只影响试听。浏览器只能确认下载已发起。
- 小屏做了排版适配，但首次完整交互验证基于隐藏桌面 Chromium；手机真机、Safari
  延迟／兼容性及实际听感尚未验收。无账号、云保存、追踪脚本或后端服务。

## 源码与构建

- `website/`：宣传页、顶栏和下载链接；`web/index.html`：在线编辑器入口。
- `src/workstation/app/web-demo*.ts`／CSS：网页适配和工具栏。音乐草稿使用独立内存
  素材库；没有接入桌面本机目录、用户现有歌曲或旧的编排／共创界面。
- `vite.web.config.ts`：输出 `.cache/website/play/`，相对资源路径可部署到
  `/RootSound/play/`。共享音源路径默认仍是桌面根路径，网页使用构建基址。
- `scripts/build-web-demo.mjs`：复制宣传页、编译在线编辑器、实际裁剪 SF2、复制
  八种音色的便携采样与全部许可，生成 `.cache/website/` 发布目录。

```powershell
npm run build:website
npm run test:website
node scripts/test-web-demo.mjs
```

最后一项需要本机发布缓存里的 Electron，始终隐藏且所有音频上下文为离线替身；
不观察桌面、不输入到用户窗口、不打开物理声卡。验证真实构建在网站子路径下的
绘制／撤销／播放暂停／音频导出／工程重开，并生成隔离的桌面和手机布局图片。

## 发布

`.github/workflows/pages.yml` 在 main 上网站／在线编辑器／共享音乐源码等相关输入
更新时运行，也可在 GitHub Actions 手动启动。使用 Node24、`npm ci` 和
`npm run build:website`，仅将 `.cache/website/` 上传 Pages。无用户歌曲／实验数据／
本机缓存上传。首次构建只需仓库内已有依赖和源音色；不依赖本机编译产物。

下载初始指向现有 preview261103 Release；页面可从公开 API 更新最近同时具有
Windows／Mac ZIP 的版本，失败保留直链。原宣传页演示素材流程已停用，历史见
提交 f0ae5580。
