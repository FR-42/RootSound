## 目的和验收——用户定案

简乐仍处于早期开发。用户正式确认替代方案后，及时从当前项目移除已废弃的界面、旧设置、无用资源和构建。原生 `.rootsound` 歌曲从首次对外发布的 Release 起应持续向后兼容，不设后续时间截止。用户于 2026-11-18 澄清，起点是首次公开 Release，而非首次上传 GitHub 仓库：`preview261103`（“先导”），提交 `58cebb3db902ffc1dddc12d13672792ae7769eb9`，北京时间 2026-11-04 00:23:02 发布，https://github.com/FR-42/RootSound/releases/tag/preview261103 。此前开发版专属、且不再被首发及后续歌曲所需的兼容实现可以移除。保留或替换读取、转换及解释支持范围内歌曲音源数据所必需的实现，但不必保留旧界面、旧启动流程或旧配置行为。通用文件格式与框架自身的兼容处理不属于这次清理范围。随软件提供的演示曲采用当前格式和资源。这替代此前“旧歌曲无需兼容”的笼统表述；这是兼容原则，不代表已经逐份验证全部历史文件。

当前的卷帘、音符、音色卡、控制台、播放及演奏曲线属于必须保留的现行功能，不作为旧兼容残留清理。

用户于 2026-11-18 后续修改了按来源命名的决定：默认名称统一使用实际精选音色名称，包括 MIDI 导入，不能加编号。独立声部可以同名，保留各自标识、MIDI 乐器编号、打击键、音符和曲线。已有工程中可确认的 GM 默认名在加载时转换，用户自定义名称保留。用户随后取消了原有 10 张音色卡上限，并授权直接修改。手牌区域支持上下滚轮横向翻动，卡片沿扇形转入钢琴下方隐藏，不增加手牌左右牌堆；钢琴上原有音色库的牌堆行为保留。

简乐是一款帮助普通人快速上手、在创作中高效获得反馈的音乐创作软件。降低学习与操作负担，
让用户更快进入创作。潜在用户包括小学或初中的低龄用户、40 岁以上人群，以及完全没有音乐制作经验的普通人。
先把一段原创片段做到满意，再沿同一流程扩为整曲。首个听感参照为 Vulcanus 的 0–20 秒，
重视人声和背景旋律；它不规定原创长度，不授予原录音所有权，也不代表过去实验已验收。
创作辅助方式、原创新段长度和具体音乐满意标准仍待确认。代码通过不等于听感、易用性、
市场需求或专业真实感通过。Windows 桌面优先，基本功能离线、完整工程可移机继续编辑。
账号、云服务、在线 AI、重新推倒架构都不是由此自动获准的需求。
来源：D-2026-10-27-10、D-2026-10-23、D-2026-10-22-4。

## 当前创作入口——用户定案

对外名称为“简乐”，仓库和技术名称仍为 RootSound。桌面主页直接显示物理乐曲库，打开一份音乐
直接进入单一可编辑乐谱。旧编排／乐句总览、旋律／节奏分屏和共创不是当前发布入口。
纵向钢琴卷帘横轴为音高、纵轴为时间，音符组独立编辑。
此前的多卷帘设计已替代。界面精简、播放控制居中。速度段使用细单行标签，点击弹出 BPM、“敲击定位”和格数；
各段速度／格数独立。首个控制块固定显示。点击卷帘区域会切换琴键左侧 BPM 的调节对象。
右键删除卷帘时，上方卷帘接管同一拍区间，音符保留。首个卷帘始终保留，仅剩一个时可关闭「多卷帘」。
最下方的拖动边缘带向下淡出的阴影。旧“删掉空设置”已由明确的学习／高级功能设置替换；旧图片教学、
编辑器内旧教程步骤已由直接操作真实编辑器的练习替换；网站旧引导现已撤下，保留普通在线编辑。
2026-11-21 用户批准一首乐曲只使用一个 BPM。打开和导入时采用开头 BPM，按旧时间轴的实际秒数换算音符、曲线和 MIDI 事件的位置。手动保存后才写入文件。移除分段卷帘的命令和开关，欢迎页和编辑页的播放线改为淡黄色向下渐隐。
BPM 面板可选整首音乐的拍号，默认 4/4，和每拍细分独立。切换拍号保留音符时间。
2026-11-16 用户决定取消卷帘左侧的小节序号和单独的小节线。卷帘节奏网格显示拍线与细分格线，此决定替代旧的小节线样式要求。
来源：D-2026-11-02、vertical-roll、roll-label、hands-on-guidance。

## 编辑、时间与播放——用户定案

2026-11-10 更新：创建或拖动音符时，音符头靠近可见的拍线或格线会轻微吸附，
离线较远时仍可自由放置。持续时长与键盘步进遵循各自规则。
Q/W/E/A/S/D 编辑微调及双 A/D 移拍已明确取消；标准组合快捷键和可选键盘演奏另行保留。
工程视口、选择、光标、组内默认时长独立于音乐正文保存。新音符可复用该组调整过的长度；
平移、缩放、浏览不自动保存音乐。裁剪屏外 DOM 时仍保留选中／编辑音符可用，播放线不能
每帧复制乐谱或强制布局；真实 FPS、延迟需要测量，不能用结构检查冒充。
暗淡组不响应选择、拖动或擦除。有音符的组移除需确认，连续两次 Delete 可移除选中组，支持撤销。
同音色组可拖拽合并，保留重叠／隐藏音符、身份、混音和 MIDI 演奏通道，一次撤销恢复；
2026-11-18 用户批准取消合并后的自动选中：保留原有有效选择，清除已被合并移除的源卡选择和输入状态，不因合并主动选中或固定其他卡。拖动结束的跟随点击不应误选；之后主动点击仍遵循原有选中／取消行为。
未定义或不同音色组不能合并。播放到最后有音符的小节末尾暂停归零。组独奏、试听总增益和
WAV 导出增益含义不同，不恢复输出增益抽动。旧兼容模型的固定秒长／BPM 规则有差异，
按当前时间合同保留明确秒长、拍长和源速度表，不能拿旧一句话覆盖所有模型。
来源：free-onsets、remove-qweasd、workspace-memory、editable-sounds、group-merge、playback-end、RB139–141。

## 文件、乐曲库与保存——用户定案

2026-11-18 用户确认新版安装包范围：Windows 与 macOS ARM64 同时制作，本地交付，由用户手动发布。安装引导按当前软件美术风格重构，下载文件名简化。默认和自定义安装目录均需支持后续升级、保留歌曲并清理旧程序。Windows 首次默认安装位置仍不选 C 盘、优先 D 盘；终端用户可以主动选择 C 盘上的自定义目录。这不改变 worktree 禁止默认放 C 盘的约定。用户已批准本次 release Prompt，并进一步确认 Windows 安装版改用根项目实际使用的原生 .NET/WebView2 桌面代码。macOS 仍用 Electron；Windows 专用鼠标输入、顶栏行为尚未移植并实机验收，不能宣称两个平台所有交互已完全一致。

桌面乐曲库按 project 的实际目录逐层浏览，使用可滚动的单列列表。用户于 2026-11-18 修改此前的点击规则：歌曲或文件夹单击立即打开，取消双击改名，改名统一放在右键菜单中；另存为乐曲库也保留右键改名入口，同时维持保存位置选择的原有语义。Prompt 获批后已实现：移除打开计时和双击改名处理，忽略双击中的第二次点击，另存为右键只提供本次要求的改名入口。点击面包屑切换目录。界面绘制视口附近的条目，在后台读取时长。
原生工程、MIDI/RMI、MusicXML/MXL 和受支持便携工程共用打开路径；打开 MIDI 不自动生成
.rootsound。当前工程已有 .rootsound 文件时，「保存」写回原文件并留在编辑器。
另存为、新项目首次保存和导入乐曲保存时，使用同一套目录列表选择位置，预填曲名。同名冲突时自动加数字后缀。乐曲库可新建文件夹，并对文件和文件夹改名或删除。
详情页无修改时直接退出当前乐曲。有修改时，首次点退出，退出变红、保存变绿；提示仍亮时再次点击会丢弃编辑并退出，快速双击同样生效。三秒后或执行单纯移动鼠标以外的其他操作后，提示颜色自动恢复。保存或另存为成功后回到详情页，恢复按钮颜色，三个文件按钮短暂亮白，未保存星号消失。窗口关闭按钮直接退出。另存为需要在选定的目录内确认保存才写入文件。
乐曲库和详情页改名同步真实文件路径与当前保存目标。可编辑文字输入区域采用彩色矩形底，用色彩变化反馈焦点。
普通编辑留在草稿，明确保存才写音乐文件；外部改动冲突不能静默覆盖，验证后原子写入，
不恢复自动 .bak。完整工程包含用户自有采样和编辑内容；破坏性操作保持明确范围。
来源：music-files、folder-library、library-minimal、library-arrows、no-bak、explicit-saving。

2026-11-05 用户确认：旧工程转换时可以缩短末尾空白，不影响项目。所有音符、开始时刻、
持续时长、声音参数和实际发声尾音仍须保留；不扩大为可以裁掉音符间的音乐休止。

## 架构与归属——已确认原则

保留可替换任务模块、共同公开合同，以及共同规范下的同级自由交流。统筹中心不执行音乐 DSP，
也不逐条中转所有模块交流。声音运行是实时试听／播放／离线输出的共同执行边界，创作模块
拥有音乐含义与编辑职责，试听不要求先打开声音运行界面。普通编辑隔离，联合修改须明确选择。
公开接口形式、内部部门、容器、技术和具体预算，未经用户特别定案都属于可调整工程选择。
当前源码布局见 docs/ARCHITECTURE.md。来源：D-2026-10-22-2/-3/-6、D-2026-10-23-5、product-independence。

## 工程暂定值，不扩大为产品承诺

当前 1–1000 BPM、MIDI 音高 0–127、1024 拍、128 组、共享 50000 事件预算；网页限制更小。
MIDI 编码不能表示原生格式的全部速度范围，应拒绝不支持的编码，不截断。修改时核对常量和
MUSIC_FILES.md。视口阈值、调度、结构、格式和框架可以调整。验证范围见 CURRENT_STATE.md、TESTING.md。

## 桌面鼠标交互

- 2026-11-19 用户批准方案一。音色卡正面用彩色边缘、白色名称和真实乐器照片。本曲手牌移到编辑区底部，左下方牌堆将音色库展开到上方；展开时压暗卷帘，保留下方手牌与虚线收起槽。当前编辑器移除琴键和纵向列线。BPM 与添加卷帘移入详情页。

- 边缘判定同时要求朝边缘快速移动和抵达或越过实际窗口边缘。只靠近边缘或贴边继续推都不触发。左边缘开关音色卡，右边缘开关详情页，上边缘取消音色选中。详情页打开时左滑仍留在详情页，切换共用 0.5 秒冷却。
- 未打开乐曲时，桌面显示欢迎页，向右挥到右边缘打开乐曲库，再向右边缘挥一次返回。乐曲库仍从底部展开，关闭时倒放动画。卷帘采用静态渐变，音符发声时仅亮起边缘。
- 详情页覆盖卷帘和琴键。乐曲名下方是文件操作，音量左侧排列 0.5x、0.75x、1x 三个相邻倍速块，选中块变色。随后是网格线浓淡、鼠标灵敏度，最后是多卷帘。三个滑杆加粗并左右对齐。多卷帘开关用一片或两片错开的形状表示状态。
- 2026-11-18，用户修订 Windows 桌面版的“紫莓 × 青碧”配色。文本框使用浅青、浅紫、浅粉渐变及深色文字，选区使用深色紫莓渐变及浅色文字。音色牌背保留深色紫莓渐变。倍速仅在选中时显示渐变色块，未选中项背景透明。
- 桌面音符完整覆盖计划的开始至结束时间，不通过内缩或缩短色块制造首尾缝隙，短音符也不例外。用户随后选定 0.5 像素黑色内描边和 1 像素小圆角，保留从上到下的同色渐变。音符按可见列线之间的区域居中：音高方向偏移实际列线宽度的一半，高亮叠层采用相同校正。选中、悬浮及播放的浅色描边保留在黑边内侧，不带周围阴影。音乐时间不变。此前过大的圆角和人为首尾缝隙因不能准确表达时间而被用户否决。
- 欢迎页、乐曲库和编辑器始终显示 Windows 原生顶栏。标题栏位于工作区上方，可拖动窗口、最小化、最大化、还原及关闭。
- 播放和试听的高亮沿白键和黑键的可见轮廓绘制。
- 选中音色时，编辑区上沿显示音色向下淡出的渐变，中央显示音色名称。快速划到窗口上边缘取消选中，卡片回到手牌。
- 点击虚线框时，摊开的音色卡收回牌堆。打开设置时暂时盖住手牌和牌库，退出设置后恢复原有显示状态及牌库位置。牌库摊开时卷帘仍可编辑，滚轮位于牌组上时翻牌。
- 用户选定最初的“流线”牌背：紫莓渐变底上两条浅暖色细线，撤回了中部鼓起及加点的变体。牌堆用清楚的纸边与错层区分多张牌。用户认为翻面动画太慢，要求摊开和收回恢复为此前的 240 毫秒位移、缩放及淡入淡出，逐张错开 14 毫秒。中途切换时从当前显示状态继续。动画交给浏览器合成执行，不在每帧反复读取布局。
- 进入卷帘周边区域即可平移，越靠近边缘越快。快速移动鼠标会暂停自动平移，鼠标放慢后在有效区域恢复。按中键切换自动平移。按键打断后，鼠标经过中央区域才能恢复。
- 桌面视角可以越过乐曲起点，方便操作开头的音符。起点上方延续列线，不绘制拍线和细分行线。缩放与视角恢复保留这片空间，音符时间仍不能为负。
- 选中音色卡后，只播放该卡的音符。悬浮本曲手牌中高亮的音色卡时，临时优先播放悬浮音色；移开后恢复已选音色，没有选中项则恢复全部音色。关闭手牌或删除卡片时清除临时试听范围。切换只调整分组音频增益并作短暂平滑过渡，保留完整乐曲时钟和声源当前位置，不重新准备采样或重建乐谱。
- 普通滚轮首次操作用鼠标圆心判定。已选中音色且圆心落在空白处时，向下滚动添加音符。开始编辑后，原地滚动始终作用于同一颗音符，缩出圆心后也继续编辑，删除后保持删除结果。滚轮开始滚动卷帘后会在原指针位置持续滚动。移动鼠标后，下次滚动重新判定目标。
